# Orbbound

## 1.5.0 握持布局与平滑转向

- 首页去掉大块空白面板，上方标题与球体重新排布；操作区集中在屏幕中下部，上下保留握持留白。
- 顶部菜单和提示保持位置，棋盘整体上移并保持 640:760 比例；长屏操作区中心约在屏幕高度 69% 处，小屏自适应缩放。
- 转向由 40ms 定时跳动改为逐帧时间积分：按下立即微调 1°，初速 18°/秒，加速度 60°/秒²，最高 90°/秒；松手、暂停、发射时停止，换向重新加速。
- 辅助线落点计算复用本次棋盘坐标，减少重复遍历；本机 500 组轨迹与 1.4.0 完全一致，单次基准耗时约从 81ms 降至 58ms（非手机帧率承诺）。
- 22 项自动测试通过，覆盖 30/60/120 FPS 转角一致、松手停止、换向、暂停与角度限制；检查 320×568 和 412×915 界面。未进行实体手机安装及性能实测。

下载：[1.5.0 APK](https://github.com/Nanami0923/Orbbound/releases/download/v1.5.0/Orbbound-1.5.0-Android.apk)。沿用原包名和签名，可覆盖安装；versionCode 为 10500。

## 1.4.0 手机操作更新

- 首页与局内改为固定单屏，禁止页面横向、纵向滚动，适配系统安全区；设置和历史弹窗内部仍可滚动。
- 左上集中游戏菜单和暂停，菜单内提供设置、历史、重开、回首页；右上显示下一球和玩法提示。
- 底部固定「逆时针 / 发射 / 顺时针」三个按钮；点按转动 1°，长按连续转动，角度限制为 ±78°。
- 手机版禁止棋盘触摸瞄准和发射；取消设置中的独立发射选项，旧设置不影响新版操作。
- 包名和发行签名与 1.3.0 一致，可覆盖安装；versionCode 升至 10400。
- 验证：19 项自动测试，含移动端触摸禁用、旋转方向/边界、暂停和结算期间输入锁定；320×568、390×844 浏览器界面及操作检查。未进行实体手机安装实测。

下载：[1.4.0 APK](https://github.com/Nanami0923/Orbbound/releases/download/v1.4.0/Orbbound-1.4.0-Android.apk)。本地输出：`最终交付/Orbbound-1.4.0/Orbbound-1.4.0-Android.apk`。

## 1.3.0 安卓版

- 新增 Android 7.0 及以上可安装的离线 APK，包名 `com.orbbound.game`，versionCode `10300`。
- 手机界面压缩顶部信息区，按屏幕高度缩放棋盘，保留拖动瞄准、松手发射和独立发射按钮。
- 切后台自动暂停并保存；系统返回键依次关闭弹窗、返回首页、将应用放入后台。
- 本地成绩、设置和续局保存在应用内；卸载或清除应用数据会删除记录。
- 下载：[GitHub Release v1.3.0](https://github.com/Nanami0923/Orbbound/releases/tag/v1.3.0)。

本机构建需要 JDK 21、Android SDK platform 36 和 build-tools 36.0.0，设置 `JAVA_HOME` 和 `ANDROID_HOME` 后运行：

```powershell
npm ci
npm run package:android
```

输出：`最终交付/Orbbound-1.3.0/Orbbound-1.3.0-Android.apk`，附 SHA-256 校验文件。
首次打包会创建专用发行签名，保存于 `%LOCALAPPDATA%/Orbbound/signing`，密码通过 Windows DPAPI 加密。后续版本复用该签名以便覆盖安装；请保留该目录与当前 Windows 用户环境，迁移构建机前应安全备份和导出签名。签名资料不提交 GitHub。

验证：规则及生命周期测试、生产构建、手机尺寸浏览器检查和 APK 签名校验。尚未连接实体安卓手机进行安装实测。

## 1.2.0 修复

- 棋盘下降时翻转六角行偏移，渲染、邻接搜索和射线预测共享该偏移；保留既有小球位置关系。
- 下降动画结束前锁定下一次发射；换局时恢复暂停的动画管理器，修复漫游独立发射卡住。
- 界面改用“同色消除 / 悬空掉落”和剩余发射次数倒计时，难度显示简单、普通、困难及具体开局参数。
- 新规则标识为 classic-v2。旧版未完成对局不加载，保留原记录并提示重新开局；历史成绩和设置不变。
- 15 项测试通过，含 60 组开局、超过 1,000 次发射的回归覆盖。

基于《Snood 现代化重构方案》的原创桌面版 MVP。保留“匹配—断连—掉落—危险条”的策略核心，不使用原作名称、素材或声音。

## Windows 10 EXE

1.2.0 为 Windows 10 x64 目录版：

`最终交付/Orbbound-1.2.0/win-unpacked/Orbbound.exe`

双击即可运行，无需安装。它是未签名的本地构建，Windows SmartScreen 可能显示提示；确认文件来源可信后再运行即可。

重新打包：

```powershell
npm run package:win
```

打包目标为 x64 目录版，Electron 只负责承载 `dist` 静态资源，不需要服务器或联网。复制游戏时必须保留整个目录。
