# Orbbound

## Windows 1.3.0（独立版本）

- 高清画布 1280×1520、小球纹理 192×192；移除外投影，描边限制在球体内，避免相邻小球遮挡。
- 保留桌面左右信息栏和居中棋盘，鼠标瞄准、点击发射及键盘微调。
- 复用棋盘小球对象、合并消除动画、飞行位置连续插值，减少对象重建和跳动。
- 无辅助线炮口由旧 Windows 版的 36 延长到 84 游戏坐标单位。
- 桌面打包使用独立最小清单，排除 Android 运行依赖和开发文件；只保留中英文运行语言，使用 7z 固实压缩减小下载体积。

游戏目录：`最终交付/Orbbound-Windows-1.3.0/win-unpacked`，双击其中的 `Orbbound.exe`。下载压缩包后用 7-Zip 解压整个目录。

[Windows 1.3.0 下载](https://github.com/Nanami0923/Orbbound/releases/tag/windows-v1.3.0)

Windows 版本由 `electron/windows-package.json` 管理，发布标签使用 `windows-v*`；Android 版本仍为 1.7.0，原 APK 与标签保持不变。桌面存档继续使用 `%APPDATA%/orbbound`。

验证：24 项自动测试通过；1280×800 和 900×540 桌面视口、鼠标发射结算检查通过；构建目录启动检查通过。未做不同配置电脑的帧率基准测试。

## 1.5.0 握持布局与平滑转向

- 首页去掉大块空白面板，上方标题与球体重新排布；操作区集中在屏幕中下部，上下保留握持留白。
- 顶部菜单和提示保持位置，棋盘整体上移并保持 640:760 比例；长屏操作区中心约在屏幕高度 69% 处，小屏自适应缩放。
- 转向由 40ms 定时跳动改为逐帧时间积分：按下立即微调 1°，初速 18°/秒，加速度 60°/秒²，最高 90°/秒；松手、暂停、发射时停止，换向重新加速。
- 辅助线落点计算复用本次棋盘坐标，减少重复遍历；本机 500 组轨迹与 1.4.0 完全一致，单次基准耗时约从 81ms 降至 58ms（非手机帧率承诺）。
- 22 项自动测试通过，覆盖 30/60/120 FPS 转角一致、松手停止、换向、暂停与角度限制；检查 320×568 和 412×915 界面。未进行实体手机安装及性能实测。

下载：[1.5.0 APK](https://github.com/Nanami0923/Orbbound/releases/download/v1.5.0/Orbbound-1.5.0-Android.apk)。沿用原包名和签名，可覆盖安装；versionCode 为 10500。

## 1.4.0 手机操作更新

```powershell

```

首次打包会创建专用发行签名，保存于 `%LOCALAPPDATA%/Orbbound/signing`，密码通过 Windows DPAPI 加密。后续版本复用该签名以便覆盖安装；请保留该目录与当前 Windows 用户环境，迁移构建机前应安全备份和导出签名。签名资料不提交 GitHub。

## Windows 10 EXE

当前 Windows 1.3.0 为 Windows 10 x64 目录版：

`最终交付/Orbbound-Windows-1.3.0/win-unpacked/Orbbound.exe`

双击即可运行，无需安装。它是未签名的本地构建，Windows SmartScreen 可能显示提示；确认文件来源可信后再运行即可。

重新打包：

```powershell
npm run package:win
```

打包目标为 x64 目录版，Electron 只负责承载 `dist` 静态资源，不需要服务器或联网。复制游戏时必须保留整个目录。
