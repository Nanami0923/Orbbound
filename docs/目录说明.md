# 本地目录与平台边界

## 源码

| 位置 | 用途 |
| --- | --- |
| `src/`、`index.html` | 共用游戏规则、界面及浏览器入口 |
| `android/` | Android 原生工程、版本号与构建配置 |
| `electron/` | Windows 外壳及独立版本清单 |
| `tests/` | 游戏、存档、计分、转向等自动测试 |
| `scripts/package-android.ps1` | Android 本地打包入口 |
| `scripts/package-win.cjs` | Windows 本地打包入口 |
| `scripts/benchmark-aim.mjs` | 保留的历史瞄准性能对比工具，依赖本地 v1.4.0 Git 标签 |
| `docs/design/` | 最初设计方案 |
| `docs/releases/` | 原 README 完整版本历史及散落的历史发布说明 |

源码仍共用一套 Git 仓库，平台工程保留在原位置，避免破坏 Capacitor、Electron 和构建路径。Android 与 Windows 的版本号、成品和发布说明独立管理。打包 Windows 会使用当前共用源码，并不自动回退到历史 Windows 发布时的源码；归档的旧版本成品没有被重新构建。

## 本地交付与发布位置

```text
最终交付/
├─ 版本索引.md
├─ artifacts.json                 # 成品路径、大小、SHA-256
├─ Android/
│  └─ Orbbound-<版本>/             # APK、校验值及已有更新说明
└─ Windows/
   ├─ Orbbound-Windows-1.0.0/     # 两份早期构建按来源区分
   │  ├─ release/
   │  └─ release-win/
   └─ Orbbound-Windows-<版本>/    # 完整运行目录及已有压缩包
```

后续 Android 成品放入 `最终交付/Android/`，Windows 成品放入 `最终交付/Windows/`。对应平台的更新说明整理到 `docs/releases/Android/` 或 `docs/releases/Windows/`。历史说明保留原文，其中的旧本地路径以新的版本索引为准。

`最终交付/` 已被 Git 忽略，成品不进入源码提交。将来只有在明确要求发布时才上传相应平台的成品；目录整理当时未上传；Windows 1.4.0 后续发布按用户明确要求提交。历史远端标签、发布及下载链接保持原样。

## 临时文件

- `dist/`：默认 / Android 网页构建结果，由构建命令重新生成。
- `.build/windows/web/`：Windows 专用网页构建结果，包含独立版本标识。
- `.build/windows/`：Windows 打包暂存位置，代替混杂的根目录 `release/`。
- `android/**/build/`、`android/.gradle/`：Android 构建中间文件及工程缓存。
- `node_modules/`：保留开发依赖，方便继续开发。

临时文件与交付目录都在 Git 忽略范围内。清理旧浏览器测试目录、预览截图、重复 APK 和构建中间文件时使用系统回收站；没有清空回收站。已核对重复 APK 与归档 APK 的内容一致。所有独有历史版本、源代码、Git 历史、SDK 路径配置、签名密钥和用户存档均保留。
