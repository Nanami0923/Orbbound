# Orbbound 4.0.0 · 闯关启程

Android 与 Windows 同步更新到 4.0.0。

## 新增闯关模式

- 首批 12 关、3 个章节、共 36 星：连接与消除、拆解支撑、路线与空间。
- 固定棋盘和随机种子，同样的操作可复现供球；仅从棋盘现存颜色中补球，自动替换已清空颜色的排队球。
- 9 关限发清空（其中 1 关带空间下压）、2 关白圈目标球、1 关 90 秒限时清空。
- 目标球直接消除或断开支撑后掉落均可；空间挑战每 6 发下移一行，不补入新球。
- 限时关只计算可以瞄准发射的操作时间，飞行、消除动画、菜单和后台均不扣时。
- 通关解锁下一关；开局前显示一至三星条件，保留最佳星级、发数与用时；支持重试、下一关和返回选关。
- 闯关存档与无尽、限时存档独立，星级进度纳入备份导出与导入，闯关成绩不混入原排行榜。
- 保留现有鼠标键盘、手机双滑条和沉浸式操作。

## 安装

Android：安装 `Orbbound-4.0.0-Android.apk`。沿用原应用标识和签名，支持覆盖旧版保留数据，版本码 40000。

Windows：完整解压 `Orbbound-Windows-4.0.0-x64.zip`，运行 `Orbbound/Orbbound.exe`。继续使用 .NET Framework 4.8 与共享 WebView2；压缩包不包含运行环境。存档位置保持不变。

每个安装包均附带 SHA-256 校验文件。旧版本安装包继续保留。
