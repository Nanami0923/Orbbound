## 原生实机与交互

验收应用为隔离包 `com.orbbound.game.lantest`，版本 `5.2.2 / 50202`，一台 Android 16 实体手机，WebView 视口 400×869、DPR 3。实体手机通过 Wi-Fi 加入生产 Windows C# TCP/UDP 房主及两名同机客人组成的真实四人对战房间。该场景包含一台手机和三个运行在电脑上的真实会话，不是四台独立实体设备。

- 普通和沉浸模式均取得收起/展开实机样例，UI 已获用户确认。实机主棋盘 378×449.25，打开和关闭信息窗均未改变棋盘位置或尺寸。
- 通过原生触摸分别点击浮窗外的普通发射按钮区域和沉浸棋盘区域，浮窗关闭，房主权威记录中的手机发射次数增量均为 0。
- 实体安卓返回键先关闭信息窗，没有打开离房确认；关闭按钮、Escape、窗内点击和长内容滚动另由浏览器检查覆盖。
- 通过正常联机设置申请、全员同意暂停，在设置中切换普通/沉浸模式。暂停后重开信息窗等待 600ms 仍保持可见，关闭后各选手准备恢复成功。
- 实机检查未记录页面异常。此轮重点是界面、输入与暂停/恢复，未将定时结束的 QA 房间记作自然胜负验收。
