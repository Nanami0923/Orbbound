# Orbbound 5.0.0 更新说明（候选测试版）

5.0.0 为 Windows 与 Android 双端界面更新。整体采用低高光、低边框密度的深色面板风格，略微提高色彩饱和度，同时保留原有泡泡图案、颜色识别和游戏操作逻辑。

首页与局内界面统一字体、数字层级、面板和按钮。发射器与泡泡改用克制的哑光质感；背景加入极淡的几何点缀。首页演示持续自动循环，不再显示动画重播按钮。右侧操作按钮、下一球预览和危险倒计时使用一致的视觉层级。

Android 竖屏版把基础分、下压倒计时、其他数值与下一球纳入更清晰的信息栏。核心数值上移并突出，单位作为次级信息；下一球采用左右排列，必要时增加信息栏高度，为上下内容留出间距。按钮操作与棋盘沉浸操作均沿用原设置。

结算、暂停、排行榜和记录页采用统一面板语言；连击、通关和失败反馈加入轻量专属动效。动效尊重系统减少动态效果偏好。

本版保持 prerelease 候选状态，4.3.0 稳定正式版与 4.7.0 原包继续保留。公开测试包在 PR #1 合并及发布前仍为 4.7.0。构建物、SHA-256 与验收范围见[产物清单](5.0.0-artifacts.json)和[验证记录](5.0.0-validation.md)。
