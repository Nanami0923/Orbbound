## 性能采样与边界

同机短程对比，独立新建测试存储目录。以下是单次测量，不是多次平均，也不代表所有设备。

| 指标 | 3.0.0 Electron | 3.1.0 WebView2 |
| --- | ---: | ---: |
| 启动至首页截图（含自动化连接和截图开销） | 6.64 秒 | 4.47 秒 |
| 首页 JS 堆 | 6.10 MB | 2.19 MB |
| 局内 JS 堆 | 11.48 MB | 8.95 MB |
| 首次设置点击同步处理 | 16.0 ms | 2.6 ms |
| 首次设置点击至两次 RAF | 48.8 ms | 49.4 ms |
| 首次记录点击同步处理 | 0.6 ms | 1.0 ms |
| 首次记录点击至两次 RAF | 17.7 ms | 38.6 ms |
| 点击开始至局内截图（含自动化与截图） | 1.12 秒 | 1.15 秒 |

另一次最终 UI 回归中，3.1.0 设置/记录两次 RAF 等待分别为 36.6/11.6 ms；差异说明短程首开绘制会波动。确定的改进是移除旧内容、缩小首屏执行量、减少设置同步工作与重复记录格式化；不宣称每次绘制都更快。

144 Hz 桌面上各取 120 次 RAF 间隔：首页、局内、返回首页的中位数约 6.9 ms；3.1.0 p95 为 7.1–7.2 ms，未出现超过 33.4 ms 的间隔。这是浏览器动画回调间隔，不是游戏实际 FPS，游戏仍限帧 60。JS 堆不等于整棵进程树内存，启动测量也不是纯程序冷启动耗时。

模态窗口/不可见状态暂停首页动画，返回首页休眠游戏循环，最小化通知音频与对局保存。没有进行硬件功耗测量、多设备帧率统计或长时间压力试验，不据此承诺功耗、峰值内存或极端大量消除场景的改善。系统运行环境已安装且游戏资源走本地映射；未切断用户电脑网络做物理断网测试。
