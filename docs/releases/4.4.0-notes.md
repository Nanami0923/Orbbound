# Orbbound 4.4.0 · 四人联机与界面更新（测试版）

Android 与 Windows 同步更新。同图竞分和连锁对战支持 2–4 人，联机中可申请暂停后调整设置，首页与各玩法界面也做了统一整理。**本版为测试版，4.3.0 正式版继续保留。所有联机玩家都需要更新到 4.4.0。**

## 一起开局，最多四人

- 建房可选择 2 / 3 / 4 人容量。至少两人、所有已加入玩家准备后即可开局，不必等到满员。
- Android 和 Windows 都能当房主；保留房间检索、快捷填入、按地址检索及手动加入。
- 大厅显示每人的席位和准备状态，比赛显示所有对手的分数、棋盘状态和排名。
- 同图竞分触底后保留成绩并进入观战，其他人继续比赛；连锁对战出局后也可观战。结算区分正常完赛、弃权和中断，同分同波次允许并列。
- 房主认输后可以留在房间维持比赛；关闭房间会中断整局。本版不支持房主迁移或比赛中途加入新选手。

## 暂停后调整设置

局内点击「暂停 / 设置」，会立即显示申请进度；其他在赛玩家在当前页面即可看到投票。房主和客人都能申请，拒绝、取消或超时会给出明确结果。

全员同意后比赛冻结，申请者自动打开设置，其他人也可调整自己的设置。设置实时应用并自动保存；点击「完成」回到暂停面板，再选择「准备继续」。所有在赛玩家关闭设置并准备后，统一倒计时恢复。

暂停面板显示剩余时间。设置打开时不会把点击或按键传给棋盘；暂停到期也会先退出设置，再进入恢复流程。对局中只调整本机声音、操作和显示，不提供导入存档、恢复备份及全部恢复默认。

## 连锁对战的新规则

每位玩家会累计**所有其他存活选手**的消除量，人数越多，产生一行来袭所需的球数越高。同色消除与悬空掉落都计入，同一个球只算一次。

| 当前存活人数 | 其他人的合计消除量达到 | 对自己产生的来袭 |
| --- | --- | --- |
| 2 人 | 12 球 | 1 行 |
| 3 人 | 24 球 | 1 行 |
| 4 人 | 36 球 | 1 行 |

例如四人局中，另外三人分别消除 10、14、12 球，合计 36 球，就会给你的棋盘产生一行来袭。

自己的消除同时用于进攻和防御：每累计 12 球可抵消一行，优先抵消最早的来袭，再抵消同时产生的新来袭。没有来袭时，不储存整行护盾；不足 12 球的进度会保留。来袭最多积压三行，先预告再下压，避免连续瞬间压盘。

有人出局后，按剩余人数调整阈值并保留已有进度的比例，不会因人数变少突然补发攻击。最后一名存活者获胜；同批出局允许并列，到时仍有多人存活则比较分数和完成波次。主动退出与正常出局分别记录。

## 界面与操作

- 首页改为闯关、无尽、限时、局域网四个同级入口，采用 2×2 排列。继续存档、难度和时长在对应模式准备页中选择。
- 首页、选关、记录、教程、联机大厅和普通弹层使用固定页面、分页或分步操作；只有设置详情保留纵向滚动。
- 设置统一为「声音与音乐」「操作与辅助」「画面与性能」「数据与维护」四类。按设备和控制方式显示适用选项，可单独恢复当前分类默认值。
- 三种单机与两种联机统一状态区域、主要操作和设置体验，保留各模式的规则提示。
- Windows 联机使用桌面布局：鼠标左键或右键按住瞄准、松开发射，键盘操作与单机一致。手机保留按钮操作与沉浸操作。
- Android 根据设备实际震动能力显示反馈开关；无恢复副本时，备份恢复按钮会显示不可用。

联机继续保留消除、掉落和下压动画，以及随自己棋盘危险程度加速的音乐。音量、加速开关、画质和减少动态效果等设置在本局实时生效。

## 安装、兼容与验证范围

[Android 4.4.0 APK](https://github.com/Nanami0923/Orbbound/releases/download/v4.4.0/Orbbound-4.4.0-Android.apk) · [Windows 4.4.0 ZIP](https://github.com/Nanami0923/Orbbound/releases/download/v4.4.0/Orbbound-Windows-4.4.0-x64.zip) · [4.4.0 测试版发布页](https://github.com/Nanami0923/Orbbound/releases/tag/v4.4.0) · [4.3.0 正式版](https://github.com/Nanami0923/Orbbound/releases/tag/v4.3.0)

Android 沿用发行签名，可覆盖安装保留数据。Windows 请完整解压后运行 `Orbbound/Orbbound.exe`，继续使用 .NET Framework 4.8 和共享 WebView2 Runtime。旧 Windows 存档入口改为「设置 → 数据与维护 → 导入旧 Windows 存档」。

联机协议升级到 **v3**，4.4.0 与 4.3.x 不能混用。所有人需要连接可互通的局域网；网络隔离、热点限制和防火墙仍可能阻止发现或连接。普通网页预览不提供原生联网。

本版已通过 395 项共用测试（36 个文件）、22 项 Android JVM 测试和 125 项 Windows 原生检查。桌面 Java / C# 四进程网络互通，以及浏览器四端开发模拟中的 2–4 人开局、暂停投票、自动打开设置、实时画质、全员准备恢复、超时、离房和排名流程已完成检查；也完成了 320×568 非设置页面的纵向溢出检查。

**发布时没有实体手机在线，尚未完成本版四台实体设备的混合联机矩阵及 20 局真人试玩。** 浏览器四端模拟和桌面四进程互通不能替代真机验收，网络环境与多人平衡仍待实测，因此先发布测试版。
