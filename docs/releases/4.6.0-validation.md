# 4.6.0 验证记录

验证日期：2026-10-18 至 2026-10-19。基线：`ffbeb53` / 4.5.0。发布渠道为 prerelease 测试版，保留 4.3.0 正式版。

本记录区分自动测试、浏览器布局、生产网络服务驱动与实体安装包的实际覆盖范围。[实施方案](../design/4.6.0联机性能与界面统一更新方案.md)中的完整设备矩阵仍是后续验收目标。

## 自动测试与构建

- 最终全量 Vitest：45 个文件、537 项测试全部通过，无失败或跳过；`tsc --noEmit` 通过。
- Windows 打包流程：15 项 shell、12 项 bridge、98 项真实 TCP/UDP 检查通过，共 125 项。
- Android：JDK 21 强制 `:app:testDebugUnitTest --rerun-tasks`，63 个 Gradle 任务实际执行，4 套共 22 项 JVM 测试通过，无失败、错误或跳过。
- 双端正式构建成功。APK `versionName=4.6.0`、`versionCode=40600`，v2/v3 签名通过，发行证书与 4.5.0 一致；Windows EXE 版本 `4.6.0.0`，继续使用未签名的既有发行方式。
- ZIP/APK 内各 5 项网页资源与对应本次构建产物逐文件 SHA-256 一致。安装包大小及哈希见[产物清单](4.6.0-artifacts.json)。
- 回归覆盖旧 auto/缺省迁移、合法固定帧率保留、备份校验与回滚、原生刷新率边界、连续展示时钟/暂停冻结、主图与小图预算、同尺寸缓存复用、下一球阶段同步、不限暂停次数/累计时长、共享冷却及新旧规则双向拒绝。
- 真机额外复现旧有联机结算偶发停在 `0:00`：结束计时器提前不足 1ms 唤醒后失去后续调度。已修为按绝对截止时间重新调度，并增加 5 项计时器回归。

## 浏览器及设备

- 浏览器模拟覆盖默认地址加入、首屏房主地址复制、准备/倒计时/开局与联机主图；320×568 视口下关键按钮在可视区内且中心命中。该流程不等同真实网络联机。
- Windows 平台浏览器预览：1280×720 棋盘截图确认额外“当前球”提示删除；800×600 与 1920×1080 的 6 个游戏操作按钮均在视口内且中心命中。
- Windows 最终安装包原生冷启动成功，UI Automation 确认标题/主页为 4.6.0，并能读取原有闯关、无尽、限时存档入口。原生截图工具返回 `FrameArrived timed out`，因此本轮没有把浏览器截图计为 Windows 原生视觉/DPI验收。
- 实体 Android 16 手机以原签名从 4.5.0 覆盖到候选 4.6.0，再覆盖最终包，均成功，无卸载/清空数据；旧无尽存档入口仍可读取。最终包冷启动、默认地址输入与输入法收回、按地址加入均通过。
- 候选包作为真实 Android 房主，与同一 PC 上 3 个 headless 客人进行四人同图竞分；客人运行真实 TypeScript `LanSession` 与生产 C# `LanService`，使用真实 TCP。两局均正常到时结束，同一房主同一局 3 次暂停均全员同意并恢复；355 组同 `serverSeq` 的快照摘要跨客人一致，对局结束前无异常断线/日志错误。该对照是快照摘要，未冒称逐单元全棋盘比较。
- 最终 Android 包反向作为客人，连接生产 C# 网络服务房主进行两人连锁对战，完成加入/准备/开局、瞄准与发射，并在自然到时后自动进入结算页，无需额外点击刷新，验证本轮结束计时器修复。四人候选包也验证观战弹层与返回自己。
- 最终包持续瞄准截图显示 `53 FPS · 请求 60 / 调度 60`，确认活动主图不受缩略图 20 Hz 上限锁定。该读数为应用整秒绘制计数，不能作为稳定 60 FPS 或相对 4.5.0 的平均/低分位性能结论；未完成受控同种子、同负载 A/B 和长时间帧追踪。
- 独立 C# 回环驱动已通过 4.6.0 双人竞分、四人对战的握手、发射、暂停恢复与快照一致性；另运行 4.5.0 双人基线。它们不是 Windows 完整 UI 或四台实体设备验收。

原始日志、截图及测试报告保存在本机 `.build/qa-4.6.0/`，其中包含局域网诊断信息，不随仓库或 Release 发布。

低性能设备、完整 Windows DPI、四台独立实体终端及长时升温矩阵，尚未完成完整验收。默认 60 是活动调度目标，不代表系统或负载受限时必然达到；静止按需绘制不计入活动 FPS。
