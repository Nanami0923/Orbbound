# Orbbound 4.1.0

Android 与 Windows 同步更新。

- 闯关重做为 5 章 30 关、90 星：满宽 14 列，98–168 个初始球，4–6 色；逐步收紧发数，并穿插目标球、空间下压与限时挑战。
- 每关均有真实弹道通关路径验证，参考路径为 14–76 发，不代表最优解；后段需要更多支撑点选择和反弹规划。
- 修复通关后点击顶部“关闭”停留在结束棋盘：现在返回选关；遮罩关闭、Escape 和 Android 返回采用相同行为。
- 手机首页动画恢复合理高度，小屏内容可滚动，避免卡片挤压动画。
- 手机选关允许纵向滚动，30 关可滑动到底，关闭按钮保持可见。
- 保留 4.0 的历史星级与解锁资格；重做关卡重新评星。旧进行中闯关保留在备份中，不作为新版关卡续局。无尽和限时模式数据继续保留。

Android 沿用正式签名，可覆盖安装。Windows 完整解压后运行 Orbbound/Orbbound.exe，使用系统 .NET Framework 4.8 与共享 WebView2，不附带运行环境安装包。
