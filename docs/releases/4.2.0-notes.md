# Orbbound 4.2.0

Android 与 Windows 同步更新，最高支持 120 FPS 自适应。帧率上限可选自动、30、60、90、120；自动根据实际显示节奏、持续负载以及平台省电/热状态调整。系统限制和设备性能会影响实际帧率。

## 两端共用

- 加入画面清晰度、减少动态效果和实际帧率显示；静止棋盘降低绘制频率，操作时唤醒。不同帧率沿用相同规则和时间预算。
- 修正非整除高刷屏的限帧余量，单独统计实际游戏更新和绘制，不用浏览器回调次数冒充游戏帧率。
- 加入四步可跳过的实操练习：同色、支撑、反弹和当前操控方式。练习不覆盖正式存档、不入榜，帮助页可重新进入。
- 新局统一有效颜色供球；4.1 及更早的进行中对局保留原规则。新旧规则成绩分榜，旧纪录保留，可按难度筛选。
- 局内展示星级预算；统一基础分/结算分标签，结算显示个人最佳差值和榜内排名；闯关最佳星级、最少发数、最快时间分别展示。
- 关卡预览补充球符号，排行突出最近成绩并显示同规则、同难度的近期对比。
- 改善弹窗键盘焦点、首局准备超时与重试、导入内容预览和导入前恢复副本。

## Android

- 短屏普通模式压缩次要状态和控件装饰，增加棋盘显示空间；保留双滑条与沉浸模式。
- 沉浸模式早松手时显示“待发射”，支持取消；以场景就绪通知发射，菜单、后台和超时取消缓存。
- 加入系统文件选择器导出/导入 JSON 备份，取消选择不修改数据，不申请广泛存储权限。
- 原生报告显示能力、省电和热状态，按设置请求刷新率；后台撤销高刷偏好，前台恢复。
- 安全区桥接加入有限重试、有效值保留和诊断。

## Windows

- 有进度的重开先确认，取消保留原局；结算继续使用确认流程。
- 改善方向键组合、失焦及停顿后的转向行为。
- 按 WebView2 故障类型恢复，增加重载、重试和退出入口；可自行恢复的 GPU/服务故障不再直接隐藏游戏。
- 关闭浏览器专属重载/打印等快捷键；保留游戏自定义键、F11 和文本编辑操作。
- 失焦、最小化、锁屏和睡眠时暂停并保存；真正不可见时尝试挂起，恢复继续入口。
- 加入可见全屏入口与显示能力变化通知，继续使用轻量 WebView2 外壳及系统共享运行环境。

## 安装与验证范围

Android 沿用正式签名，覆盖安装保留数据。Windows 请完整解压后运行 `Orbbound/Orbbound.exe`，使用 .NET Framework 4.8 和共享 WebView2 Runtime。

自动测试、构建与实际界面的本次结果见 [4.2.0 验证记录](4.2.0-validation.md)。30 关的参考路线及角度采样见 [容差报告](4.2.0-campaign-angle-tolerance.md)。高刷、功耗和温升必须结合设备实测；本次未组织多机型、多显示器或真人逐关评估，不以模拟帧率测试替代这些结果。
