# Orbbound Android 5.2.2（预发布测试版）

联机专属信息改为可开关浮窗，给手机棋盘腾出更多空间，尤其改善普通操作模式下棋盘偏低的问题。

- 「联机信息」按钮位于「离开房间」左侧。模式、延迟、攻防状态、对手列表和联机说明收进浮窗，关闭后不占页面高度。
- 点击窗外、关闭按钮、安卓返回键或 Escape 可收起浮窗。窗外手势只负责关窗，不会顺带发球；开关也会清理按住瞄准、微调及待发状态。
- 保留得分、剩余时间、下一球，以及可直接使用的暂停和设置。棋盘顶部对齐，不缩小棋盘；短屏释放空间后可显示更大的棋盘。打开浮窗也不会挤压棋盘。
- 信息保持实时更新。新暂停申请或比赛阶段变化会自动收窗，便于处理投票与恢复；已暂停时仍可重新查看信息，开窗不会暂停比赛计时。

仅 Android 升级为 `5.2.2 / 50202`，沿用原包名和签名，可覆盖安装保留数据。Windows 保持 5.2.0。联机协议与规则沿用 5.2.0，可继续与 Android 5.2.0 / 5.2.1、Windows 5.2.0 联机。

646 项共用测试、16 组改前/改后布局对照、6 组开发会话检查通过，并完成实体 Android 的四人 Wi-Fi 联机界面验收。普通、沉浸模式的窗外触摸均未产生发射，正式覆盖升级后的现有存档、历史和设置逐值一致。UI 样例已获用户确认。

详细覆盖范围见[验证记录](5.2.2-validation.md)，文件大小和 SHA-256 见[产物清单](5.2.2-artifacts.json)。
