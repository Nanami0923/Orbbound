# Orbbound 4.5.0 · 双端布局与稳定性修复（测试版）

Android 与 Windows 同步更新，重点修复 4.4.0 的首页和菜单排版回归，并处理已定位的分页阻塞、联机等待与加载竞态。**本版以 prerelease 测试版发布，4.3.0 正式版继续保留。尚未证明所有用户反馈的卡死现象均已解决。**

## 首页与菜单

- 恢复 Android 首页的同色消除、失去支撑后掉落演示及轻触重播；短竖屏和横屏分别分配演示与四个模式入口的空间。
- 修复 Windows 选择区域父容器的大圆角对子模式卡的二次裁切，统一模式卡边界，并调整小视口下的高度分配。
- 普通确认、错误和短提示按内容收紧；较长配置、教程和结果采用有界分页或分步。设置分类首页保持紧凑，仅设置详情保留单一纵向滚动区。
- 教程不再逐字符反复测量和永久拆散原步骤。缩屏再恢复时，重新按原始内容排版，保留步骤编号、强调、字段值及当前条目。

## 稳定性与 Android 边界适配

- Android 系统栏安全区由同一条处理链负责；原生 IME 可见状态辅助输入层切换，避免只依赖两种视口高度之差判断键盘。
- 联机桥接请求增加有上界的等待、退出和会话隔离，防止迟到结果覆盖新操作。
- 按实际修改项更新设置，减少拖动音量时的刷新率请求、画布尺寸重建和无关输入重绑。
- 为场景未就绪时的返回、退后台和取消启动补充保护，清理旧加载状态。

三种单机、两种联机、30 个关卡及原有计分规则继续保留。局域网协议仍为 v3；本轮未完成 4.4.0 与 4.5.0 混用验收，联机时请所有人使用 4.5.0。

已通过 **41 个文件、439 项共用测试，22 项 Android JVM 测试及 125 项 Windows 原生检查**；Android Release 构建及 v2/v3 同签名校验成功。原生 Windows 已确认启动、显示 4.5.0 并读取旧存档，但截图和输入几何接口受限，**不将其记为原生视觉或完整 DPI 验收通过**。

320×568 浏览器完成教程、设置、限时配置、练习各 50 次往返，共 200 次，逐次按钮边界和中心命中检查通过；Windows 模式五个 CSS 视口的入口及模式卡边角检查通过。低性能设备、横屏重复压力、字体放大、完整 DPI 和四实体网络矩阵仍待验收，因此保持测试版。详见[验证记录](4.5.0-validation.md)。
