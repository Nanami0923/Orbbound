# Orbbound 4.3.1 · 双端联机更新（测试版）

Android 与 Windows 同步更新：改善房间检索，新增「连锁对战」，补齐联机消除动画和随棋盘危险程度加速的 BGM。双方都需要更新，联机协议已升级到 v2。

## 找房与加入

- 刷新按有效局域网接口分别查询，单个广播目标失败不会中断其他路径；一次扫描 8 秒，可停止，结束后显示结果。
- 新增扫描计数和连接检查；发现接收故障会有限重试，网络变化和后台恢复会重新评估扫描路径。
- 同一房间的多个地址合并显示，按实际 TCP 端口连接。房间卡片提供独立的「填入地址」与「加入」，刷新保留手工输入。
- 广播没有回应时，可输入房主 IPv4 地址，点击「按地址检索」，查询房间实际端口。最近成功连接的地址也会参与有限的单播查询。

## 连锁对战

创建房间时可选「同图竞分」或「连锁对战」，支持简单/普通/困难、3/5 分钟。

- 每累计消除或悬空掉落 12 个球生成一行攻击，单发最多生成 2 行，保留不足 12 的余量。
- 先抵消自己最早的来袭攻击，同批余下新攻击相互抵消，再压向对手。来袭最多积压 3 行，每行预告 2 秒，两次攻击下压至少间隔 3 秒。
- 保留发射压力下压；对战关闭额外时间下压。自然下压对应动作冷却结束后再留 1 秒操作窗口，避免同批连续下压。
- 攻击不清零自然压力、不改当前/下一球，使用独立补行随机流。清盘换波保留充能和来袭队列。
- 单方触底判负，同批双方触底平局；到时都存活则比分，再比完成波次。暂停、重连、认输和中断处理沿用房间流程。
- 联机记录区分两种玩法，结果展示攻击统计；旧记录按竞分读取。

## 动画与音乐

- 两侧棋盘通过权威事件展示飞行、同色消除、悬空掉落和整盘下移，补回得分浮字、对应音效及本地消除触感。
- 动画与规则时钟分开；减少动态效果不改变冷却。重复事件不会重复播放，重连从最新快照恢复。
- BGM 按自己的最低占用行更新危险程度，接近底线时加速，清除危险球群后回落；尊重加速开关和音量设置。
- 隔离旧单机场景对联机音频的更新；暂停/等待恢复、结算和退出清除危险速度。

## 安装与验证范围

Android APK 沿用正式签名，可覆盖安装保留数据。Windows 完整解压后运行 `Orbbound/Orbbound.exe`，使用系统 .NET Framework 4.8 和共享 WebView2 Runtime。

已完成 313 项前端/规则测试、22 项 Android JVM 测试、125 项 Windows 原生检查，以及真实 Android 设备与 Windows 服务互换房主的 20 轮指定地址检索和最大 64 KiB 消息互通。

**本版先作为测试版发布。** 当前实测 Wi-Fi 的广播查询没有收到应答，指定地址 UDP 查询和 TCP 连接双向成功；这不等同于已定位广播无应答的网络原因。热点、更多路由器、完整 APK/EXE 界面对局、真人平衡试玩及实际听测仍待补齐。
