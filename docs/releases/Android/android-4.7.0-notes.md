# Android 4.7.0（测试版）

- 修复窄屏结算“再开一局”文字与箭头重叠：文字与箭头使用独立列，窄屏主操作独占一行。
- 首页左侧演示球落在两球中间并同时相切，虚线路线与弹丸落点一致。
- 单机结算页顶部关闭、底部首页、系统返回及允许的遮罩关闭统一回首页；菜单设置/历史、关卡详情和取消操作按来源返回。
- 标题与按钮文字居中；联机下一球与三种单机共用同档位外观，保持飞行、装填及观战阶段正确。
- 联机时间、延迟、状态和按钮分组，对手区按人数布局，短横屏采用侧区；普通菜单分页、设置详情单滚动。
- 终局首次成功记录不再被重复改写；必需保存失败时保留可恢复副本并提供重试，不再无条件显示“已保存”。

包名及发行签名沿用，`versionName=4.7.0`、`versionCode=40700`。旧存档、设置和备份保持兼容；默认 60 FPS 与手动固定帧档继续保留。

沿用联机消息 v3、规则指纹 `4e2a4139` 和内容指纹 `f942c2f9`。4.6 / 4.7 双向混连已通过同机生产 C# 服务与真实游戏会话测试，实体终端结果另列；不能与 4.5.0 等旧规则版本混用。

本版保持 prerelease，4.3.0 继续为稳定正式版。覆盖安装、系统返回、输入法、安全区及实体联机的实际验收范围见[验证记录](../4.7.0-validation.md)；不将自动测试或同机驱动结果视为完整真机矩阵通过。
