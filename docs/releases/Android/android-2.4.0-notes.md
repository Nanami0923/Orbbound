# Android 2.4.0

- 新计分：同色消除 n 枚得 10n + 5(n−3)(n−2) 分（至少三枚）；悬空掉落 d 枚额外得 30d + 5d(d−1) 分。难度系数不变，旧成绩保留，已存档分数不追溯重算。
- 移除所有手机转向按钮。默认左侧发射、右侧双滑条；上条直接控制 −78° 至 +78°，下条中间分界、越靠两侧转向越快，松手回中停止。飞行和下落时仍可调方向。
- 设置新增左右位置调换，自动保存。
- 删除减少动画效果选项及相关逻辑。
- 音量滑条同时控制音效和 BGM，0% 静音；最高音效增益由 0.075 提高至 0.24。兼容原静音设置。
- 新增原创本地合成循环旋律，首次交互启动，后台挂起、回前台恢复。
- 辅助线使用等间距轨迹点、反弹标记与实际球半径落点圈，与发射共用轨迹计算。

验证：65 项自动测试通过；390×844 手机浏览器验证瞄准、设置调换及反弹辅助线；Android release 构建与签名验证通过。未在实体手机上试听或验证触控手感。
