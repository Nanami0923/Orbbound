# Android 2.6.0

本次只打磨操作、声音、显示和性能，不增加玩法。

## 声音与音乐

- 首页、菜单、设置、排行和结算使用原来的循环旋律；实际游玩切换到新的 32 音符旋律，节拍由 0.375 秒缩短至 0.28 秒，节奏稍快。
- 切换时短暂淡出旧曲并取消预排音符，避免旋律重叠。后台停止调度和残留音效，返回后恢复；菜单暂停游戏渲染循环。
- 音效和音乐分别调节 0–100%。旧音量迁移到两个通道，原静音设置继续生效。
- 调整声音层次：发射更轻，消除和悬空掉落更突出。设置中可试听两套音乐及消除音效。

## 触控与反馈

- 更宽的低速微调区，新增 50–150% 灵敏度；可选上滑条中点吸附（±1.2°）。
- 各滑条独立持有触点。松手、触控取消、失去窗口焦点、打开菜单、切换后台或改变窗口尺寸均清除触点和转向状态，不会自动恢复旧手势。
- 保留双指瞄准与发射；发射成功后即时显示“已发射”，结算期间显示“装填中”，配合炮管轻微后坐和按钮反馈。
- 发射 / 消除轻震独立开关，默认关闭；Android 原生短震动支持，需要 VIBRATE 普通权限，无运行时授权弹窗。
- 可调发射键宽度、控制区下移距离及左右位置；短屏自动限制下移。设置提供微调和握持位置预览。

## 文案与显示

- 精简首页、玩法、模式说明、菜单和结算文字，将冗长说明拆为短段落。
- 首页分为“瞄准，”与“让它掉落。”两行；长逗号标题按语义分行，小屏按钮支持自然换行。
- 空心双圈标记预计落点，减少与真实小球混淆；炮管转动，装填球图案保持正向。

## 性能与验证

- 碰撞检查按纵向分区缩小范围；落点选择复用球坐标并直接选取最近候选，省去候选排序。
- 1,200 条路径与 Android 2.5.0 的完整轨迹和落点逐一相同。本机 7 轮中位计算耗时：108.03 ms → 50.99 ms，约 2.12 倍。此为弹道 CPU 基准，不是手机帧率或耗电实测。复现：`node scripts/benchmark-2.6.mjs`。
- 82 项自动测试覆盖计分、弹道、音乐切换 / 独立音量 / 后台、触点中断、双指发射、轻震设置和标题分行。浏览器检查 390×844、320×640，无尽 / 限时、设置保存和最大按键尺寸。
- Android release 构建与原签名校验通过。当前无连接的 Android 真机，因此未实测双指手感、振动强度、扬声器响度或设备帧率。
