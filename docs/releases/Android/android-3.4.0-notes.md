# Android 3.4.0

- 首页右侧红球位于两个黄球中间下方，按相邻球相切的三角排列展示；移动端动画周期由 10 秒缩短为 8 秒。
- 普通模式与沉浸模式统一下一球提示：40 像素预览位于棋盘标题区右上角，难度和状态提示在左侧分行显示。下一球不再跟随发射键交换位置。
- 普通模式为两行标题留出空间，棋盘稍下移；短屏相应缩小棋盘，保留比例并避免挤压下方控制区。

正式 APK 沿用原签名，可覆盖安装保留数据。Windows 保持 3.2.0。

验证：108 项测试和类型检查通过；检查两种模式在 393×873、360×640、320×568、873×393 下的棋盘、预览与操作区，8 组布局均未越界。首页红球到两个黄球的圆心距离均为两倍半径，动画周期为 8 秒。Xiaomi 2210132C / Android 16 真机覆盖安装，检查普通模式预览布局。测试截图和环境不上传。
