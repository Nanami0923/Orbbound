# Android 4.2.0

增加最高 120 FPS 自适应与清晰度设置，短屏普通模式扩大棋盘；沉浸模式显示可取消的待发射状态。支持通过系统文件选择器导入/导出本地备份，安全区有限重试，原生高刷请求及省电/热状态适配。

共用玩法增加实操练习、有效颜色供球、规则分榜、星级预算与成绩反馈；旧进行中对局保留原规则，旧纪录可继续查看。沿用原签名，覆盖安装保留数据。
