# Android 2.7.0

- 启动时主动初始化音乐，不再等到首次触控；沿用 Android WebView 已启用的免手势媒体播放设置。静音设置仍被尊重。
- 删除中点吸附开关、存储字段和方向吸附逻辑。
- 修复设置内炮管预览布局：固定旋转基点、保留两侧旋转空间及角度读数宽度；离开子页停止预览。
- 取消系统矩形触控高亮，按钮改用自身圆角范围内的明暗反馈，保留键盘焦点提示。
- 新增恢复默认设置页面，立即保存并同步音量、操作和显示；保留存档与排行。
- 设置分为声音与音乐、瞄准辅助、操作与反馈、按键布局、恢复默认；子页返回上一级，Android 返回键和点击遮罩同样逐级返回。
- 优化音效打断：同类声音平滑替换，掉落音替换消除音，结算音优先并保留完整尾音；离开试听页面停止残留音效，限制叠加数量。
- 修复可能造成爆音的包络问题：音符节点初始增益归零，取消未播放音符时保持静音，已播放音符保持当前音量后淡出；无关设置变化不再重复调度音量。最终输出增加有界软限幅。

验证：86 项自动测试通过；小屏 320×640 检查分级菜单、极限角度预览、恢复默认及重新加载后的保存结果。正式 APK 沿用原签名。

当前未连接 Android 真机，启动自动播放和扬声器爆音消除效果尚未进行设备实测。
