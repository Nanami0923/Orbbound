# Android 3.3.0

- 普通模式：下一球放大到 40 CSS 像素，放在发射键下方；左右调换时一起移动。移除炮口旁重复的小预览。
- 沉浸模式：棋盘进一步下移，下一球位于棋盘标题区右上角，原状态提示换行到左侧。横屏保留紧凑布局。
- 连续发射：上一球飞行时可以开始下一次瞄准，准备完成后松手即可发射；提前松手最多缓冲一次，等待不超过 1.6 秒。新手势覆盖旧缓冲，菜单、后台、越界和手势取消不会留下延迟发射。
- 游戏菜单新增“放弃本局…”二级菜单，可选择“放弃并重开”或“放弃并退出”。退出删除本模式存档，保留放弃记录但不入榜，也不会被后台自动存档重新写回。
- 背景和弹窗遮罩延伸至系统状态栏与导航栏，安全区只给操作界面留白，消除上下分离色带。

沿用原签名，覆盖安装保留旧数据。系统静止长按约两秒可能触发厂商图片识别，按此前确认继续保留该行为。

本次仅发布 Android 3.3.0；Windows 继续使用 3.2.0。
