# Android 4.3.0

加入双人局域网「同图竞分」。Android 可创建房间，也可加入 Windows 或另一台 Android 创建的房间；支持自动发现与手动输入 IPv4 地址和端口，双方均需使用 4.3.0。

房主选择简单 / 普通 / 困难，以及 3 / 5 分钟。双方准备后同时开始，使用独立棋盘、相同编号波次开局；清盘累计得分并进入下一波。到时先比分数、再比完成波次，仍相同则平局。触底保留得分，后续球序会随各自操作变化。

新增手机联机界面、对手缩略棋盘、双方分数与连接状态，保留普通和沉浸触控方式。暂停需双方同意；切后台或短时掉线会冻结比赛并尝试恢复，恢复后双方确认再倒计时。主动离开需确认并按认输处理；非主动中断不计胜负。联机记录独立于单机排行、存档和闯关进度。

原生网络服务使用 TCP 传输、UDP 发现，并处理超时、队列上限和退出清理。选取局域网接口时不要求外网验证，可在有 Wi-Fi 与蜂窝网络并存时使用相应局域网连接；热点地址从实际接口获取。前台房间与对局保持屏幕常亮，离开后恢复。当前目标为 SDK 36，增加网络状态查询权限，不申请定位或广泛存储权限。

使用同签名 APK 覆盖安装可保留现有数据，不需要先卸载。普通网页预览不提供真实原生联机；4.3.0 不包含公网匹配、房主迁移、进程重启后续局、连锁对战或协作接力。

Android 真机发现、热点、后台恢复及多机型互联尚未完成实测。Java / C# 桌面真实 socket 测试仅验证传输互通，不替代 Android 设备验收。
