# Android 4.4.0（测试版）

两种局域网玩法均支持 2–4 人，与 Windows 4.4.0 互通。房主和客人都可申请暂停；全体在赛玩家同意后，申请者自动打开设置，完成调整并全员准备后倒计时恢复。暂停申请、拒绝与超时都有可见反馈。

连锁对战会累计所有其他存活选手的消除量：2 / 3 / 4 人分别每满 12 / 24 / 36 球产生一行来袭；自己的消除每满 12 球可抵消一行。增加多人排名、弃权和出局观战，详细攻防规则见[完整更新说明](../4.4.0-notes.md)。

首页采用四入口 2×2 排列；选关、记录、教程和普通弹层改用分页或分步，只有设置详情可以上下滚动。各玩法统一状态与操作区域，保留按钮操作及沉浸操作。设置分为声音与音乐、操作与辅助、画面与性能、数据与维护，修改实时生效；震动开关按系统报告的实际能力显示，未知时提示「设备能力待确认」。

[下载 Android 4.4.0 APK](https://github.com/Nanami0923/Orbbound/releases/download/v4.4.0/Orbbound-4.4.0-Android.apk)。APK 沿用发行签名，`versionCode=40400`，可覆盖安装保留数据。联机协议为 v3，所有玩家必须更新至 4.4.0，不能与 4.3.x 混用。

共用测试及 22 项 Android JVM 测试通过；浏览器开发模拟已检查四端联机流程和 320×568 布局。**本版没有实体手机在线，未完成实体四设备矩阵及 20 局真人试玩。** 桌面 Java / C# 四进程测试不代表 Android 真机验收，故以测试版发布；[4.3.0 正式版](https://github.com/Nanami0923/Orbbound/releases/tag/v4.3.0)继续保留。
