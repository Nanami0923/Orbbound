# Android 4.3.1（测试版）

新增多路径房间检索、可取消扫描、按地址检索与快捷填入；新增连锁对战、权威消除/掉落/下压动画，以及随自己的棋盘接近底线而加速的 BGM。

APK 沿用正式签名，`versionCode=40301`，可覆盖安装保留数据；联机双方须更新到兼容的 v2 协议版本。保留普通触控和沉浸操作，减少动态效果不改变攻击和发射冷却。

已在独立 Android 测试包中与 Windows 服务互换房主，指定地址查询各成功 10 轮并完成最大 64 KiB 消息往返；当前 Wi-Fi 广播无应答，完整真机界面对局及热点矩阵仍待验证。
