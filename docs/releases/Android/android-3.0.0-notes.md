# ORBBOUND Android 3.0.0

2026-09-14 · versionCode 30000

## 更新内容

- 保留深海军蓝、薄荷绿、暖黄与珊瑚红。手机首页删除重复口号和空存档占位，采用低饱和深色模式卡，最高分归入对应模式；有存档时主入口直接继续，新游戏作为卡内次要操作。
- 首页采用中心发射的左右两段演示：左侧两颗绿球加一发绿球演示三球消除；右侧两颗黄球加一发黄球消除后，失去支撑的一颗红球掉落。不画分支连接线，五颗静态球已经足够展示两种结果。两条飞行路线均不穿过其他球体。
- 精简局内工具栏，放大得分和整局时间，区分“本回合”和“整局剩余”。缩小发射键，突出主瞄准滑条、弱化微调，保留左右调换、灵敏度与握持偏移设置。
- 下一球缩小并靠近炮台；危险线随棋盘压力增强；瞄准点阵使用低亮度中性色，保留反射提示和落点圈；悬空球先停顿、再加速坠落。
- 统一原生系统栏底色与页面海军蓝背景，移除全面屏顶部色块断层，同时关闭系统自动对比遮罩，保留明亮系统图标。
- Android 原生根容器读取系统栏、屏幕开孔与系统手势 Insets，并消费已处理的边距，避免 WebView 重复计算。首页、局内和弹窗共享安全视口，控件额外保留设计留白。
- 手机短屏布局压缩演示和卡片间距；横屏采用棋盘在左、状态和操作在右的布局。

## 切换爆音修复

首页和游戏沿用同一首旋律时不再停止并重启音符，节奏随棋盘压力调整。每个音符和音效增加独立淡出增益节点，避免取消已有音量包络造成波形突变。切后台先淡出到静音，再延迟暂停音频；处理重复前后台事件、快速切回和异步暂停竞争。

## 验证

- TypeScript、Vite、Android release 构建通过；APK v2/v3 签名校验通过。
- 15 个测试文件、91 项自动化测试通过，覆盖计分、存档、模式、瞄准、触控生命周期及音频切换。
- 小米 2210132C（Android 16，1440×3200）从 2.8.0 覆盖安装至 3.0.0，既有记录与设置保留；最终动画修订也已覆盖安装。
- 真机完成三键与手势导航检查、无尽开局/存档、限时存档续玩、发射/瞄准、菜单/首页及前后台切换。三键模式导航栏从物理 y=3035 开始，首页底部入口结束于 y=2982，保留 53 像素间隔。测试后恢复原来的手势导航。
- 浏览器检查 320×568、390×844 竖屏及 844×390 横屏；320×568 双存档首页内容高度为 568，无多余滚动。
- 最终包再次在手势、三键两种导航下检查首页：状态栏与页面背景连续，底部入口无遮挡；中心左右发射及消除后掉落正常显示，测试后恢复手势导航。
- 用户试听反馈：“暂未听到爆音”。这不是对所有安卓设备的音频保证；测试期间切系统导航/锁屏时，WebView 曾记录音频读取超时警告，尚未建立其与可听爆音的对应关系。未进行外部录音波形分析，也未覆盖其他厂商、折叠屏和平板真机。

真机截图与演示路径检查结果位于项目 `artifacts/3.0.0/`。

## 实现依据

系统边距处理参考 [Android 官方 edge-to-edge 文档](https://developer.android.com/develop/ui/views/layout/edge-to-edge)；音频修复避开具有兼容性限制的 [AudioParam.cancelAndHoldAtTime](https://developer.mozilla.org/en-US/docs/Web/API/AudioParam/cancelAndHoldAtTime)，采用独立淡出节点。

两轮 Android 更新先合并为 3.0.0 源码提交，随后 Windows 同步通用功能并统一为 3.0.0。两端安装包发布在同一 [3.0.0 下载页](https://github.com/Nanami0923/Orbbound/releases/tag/v3.0.0)，也保存在本地交付目录。
