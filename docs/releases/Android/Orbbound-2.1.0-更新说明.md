# Orbbound Android 2.1.0

- 限时模式：次数或时间任意一项先结束，下降后同时重置两项倒计时；修复按次数下降后的计数余量。随本局游玩进度逐渐缩短时间间隔的逻辑保持不变。
- 移除手机顶部重复的下一球提示，保留并放大炮口右侧提示，关闭辅助线时也显示。
- 排行榜 / 历史记录改为直接点击标题切换，去掉原有一排切换按钮。
- 新增限时独立单局存档，与无尽存档互不覆盖。首页可分别读取；5 / 10 分钟共用一个限时存档位，新开同模式局会替换原存档。
- 存档、菜单及后台冻结游戏进度；读取后继续原剩余时间、下落时间和发射次数。兼容 2.0 最后保存的限时进度。
- 临时存档不入榜，只有正式结算后按原难度系数入榜；重开不入榜。

## 安装

直接覆盖安装 `Orbbound-2.1.0-Android.apk`，沿用原包名 `com.orbbound.game` 与发行签名，versionCode 20100。保留本地存档和历史记录，无需卸载旧版。
