# Android 5.1.0（预发布测试版）

- 闯关导航整理为章节选择、单列关卡列表和单关详情三个层级。统一应用内暗色面板与返回逻辑，保留实际章节进度、星级、锁定状态、继续存档、关卡目标和棋盘预览。
- 首页模式卡采用左图标、右文字组，图标与文字组垂直居中并增加横向间距；标题和关键状态加粗。说明文字精简，同时保留实际关卡/星级进度、存档关卡、无尽存档分数与最高纪录、限时 5/10 分钟入口。演示背景透明，循环与球面图案保留。
- 修正单机与联机下一球预览的盒体、球体和 SVG 图案边界，完整显示原球面图案及细节。
- 清除时直接消除球和连带下落球同步起动；计分、棋盘结果和发射输入锁沿用原规则。
- 备份历史记录继续校验有限、非负的 `elapsedMs`，支持合法浮点毫秒值，避免有效历史因时间字段带小数而被拒绝。

实机 UI 检查覆盖章节/列表/详情、首页和实际对局。本机 4 次真实发射样本记录到 3,160 分。自动回归结果为 58 个文件、619 项共用测试，以及 22 项 Android JVM 测试通过。4.7 / 5.1 双向会话和同机生产服务测试通过。

物理 LAN 四人局通过：Android 实机作房主，Windows 打包原生 guest 与同机两个生产 C# headless guest 加入；全员暂停/恢复、手机观战后返回、Windows 原生输入 47 轮、自然结算及两端 UI 排名分数一致（690 / 660 / 30 / 30）。共有两个实体 UI 设备，不是四台独立实体手机/电脑。单机/联机下一球预览实测为 32px 盒、28px 球，完整留在卡片内。

Android 正式包已通过原签名 4.7→5.1 覆盖升级，真实无尽存档、战役存档和设置在升级前后逐项一致；修复后含浮点时长历史的四项内置备份导入/导出也逐项一致。原 `.lantest` 应用及其八项原始键值恢复保留。系统字体放大和旋转、完整 DPI、低端设备、四台独立实体终端与长时间运行范围见[验收记录](../5.1.0-validation.md)。

本版为 prerelease 测试版，稳定正式版仍为 4.3.0。双端变更总览见[5.1.0 更新说明](../5.1.0-notes.md)，包体校验值见[产物清单](../5.1.0-artifacts.json)。
