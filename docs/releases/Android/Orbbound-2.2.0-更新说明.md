# Orbbound Android 2.2.0

- 限时模式新增两条独立下落倒计时：绿色显示剩余发射次数，金色显示剩余时间，最后 5 秒变红。任一条件触发下落后两条同时复位，整局时间继续单独显示。
- 所有模式采用更柔和的长按转向加速曲线：起步 12°/秒，随长按时间提高，约 1.8 秒达到 96°/秒上限。保留点按 1° 微调、松手即停及 ±78° 限制。
- 适当降低限时压力：简单下落间隔 36→18 秒，普通 30→15 秒，困难 24→12 秒；仍随本局进度逐渐缩短。整局时长、发射次数阈值、计分系数和榜单逻辑不变。
- 独立存档继续兼容，时间条比例随存档保存 / 恢复。旧存档当前剩余时间不重置，下一轮下落起使用新版间隔。

## 安装

下载 `Orbbound-2.2.0-Android.apk` 直接覆盖安装即可，沿用原包名和发行签名，versionCode 20200，无需卸载旧版。
