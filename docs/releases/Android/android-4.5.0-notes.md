# Android 4.5.0（测试版）

恢复首页的消除与掉落演示及轻触重播，调整短竖屏、横屏下的演示和四模式入口布局。短菜单按内容收紧，教程按语义分页，缩屏后恢复原步骤结构；设置分类首页保持紧凑，仅详情正文可以纵向滚动。

统一系统栏安全区处理，使用原生键盘可见状态辅助输入层；为联机桥接等待与退出增加期限和会话隔离，并减少设置拖动导致的无关刷新率请求和画布重建。补充场景未就绪时返回、退后台及取消启动的保护。这些修复针对已定位原因，尚未确认所有卡死反馈都已覆盖。

[下载 Android 4.5.0 APK](https://github.com/Nanami0923/Orbbound/releases/download/v4.5.0/Orbbound-4.5.0-Android.apk)。包名仍为 `com.orbbound.game`，`versionCode=40500`，沿用发行签名；Release 构建、v2/v3 签名及与旧版证书一致性校验通过。共用 439 项测试及 22 项 Android JVM 测试通过。

Android 16 实体机从 4.4.0 同签名覆盖安装成功，首页演示可见，旧无尽 / 限时存档仍被识别；教程、练习、设置及联机创建 / 加入页面可打开和返回。昵称、房主地址的真实键盘展开后，单字段编辑层与「完成输入」可达，完成或系统返回后恢复高度并保留内容。手机当时没有可用局域网，创建 / 检索返回 `NO_LOCAL_NETWORK` 后仍可退出重进，**未完成跨端联机对局**。

低性能设备、字体放大、其他输入法 / 导航方式及长时间稳定性仍需继续验证，完整范围见[验证记录](../4.5.0-validation.md)。**本版标为 prerelease 测试版，[4.3.0 正式版](https://github.com/Nanami0923/Orbbound/releases/tag/v4.3.0)继续保留。** 联机协议仍为 v3；4.4.0 混用尚未验证，建议全部成员使用 4.5.0。
