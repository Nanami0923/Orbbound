# Android 3.1.0

- 「设置 → 声音 → 局内音乐加速」选择局内是否随棋盘压力加速；默认开启，关闭后保持原速，重启保留。
- 排行榜采用紧凑列表：突出分数，将原始分、难度系数和对局信息分层展示；规则说明默认折叠，顶部模式切换与关闭按钮缩小占位。
- 前十名连续滚动，历史记录保留分页；最近一次有效结算轻量标记「最近」。数据仍是本地个人记录，不表示联网排名。
- 正式包启用 R8 和资源裁剪，并保留 Capacitor 插件与桥接所需规则。APK 从 3.0.0 的 3,587,540 字节降至 1,278,751 字节，约减少 64.4%。
- 同步游戏引擎按需加载、记录格式缓存及存储异常保护，保留 3.0.0 手机布局、系统栏与音频切换修复。
