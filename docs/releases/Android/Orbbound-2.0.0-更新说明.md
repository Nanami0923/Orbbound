# Orbbound Android 2.0.0

新增无尽 / 限时双模式入口，以及无尽、限时 5 分钟、限时 10 分钟三个独立排行榜。

- 三档难度统一按简单 ×1、普通 ×1.5、困难 ×2 加权计分。
- 限时模式不可暂停，菜单与后台不停表；按发射次数或倒计时先到触发下落，整局越靠后间隔越短。简单 30→14 秒、普通 24→11 秒、困难 18→8 秒。清盘后补充棋盘，继续挑战至到时或触底。
- 无尽模式支持存档退出、重新打开续玩，以及主动结算入榜。限时状态与无尽存档分别保存，互不覆盖。
- 旧存档可继续，已有可读取历史成绩按难度系数迁移；历史保留最近 500 局，三个榜单各自保留前十。
- 优化手机入口、设置和排行榜排版；发射时保存完整状态，避免动画中退出导致重复发射或丢分。

## 安装

下载 `Orbbound-2.0.0-Android.apk` 后直接覆盖安装。沿用原包名 `com.orbbound.game` 和原发行签名，versionCode 20000。不要先卸载，否则本地存档、成绩与设置会被删除。

Windows 1.3.0 已发布版本保持不变。
