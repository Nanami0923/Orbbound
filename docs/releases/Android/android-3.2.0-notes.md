# Android 3.2.0

「设置 → 操作与反馈」新增 **沉浸模式**，默认关闭，开启状态自动保存。

- 开启后隐藏下方发射键和双滑条，保留顶部菜单、存档和玩法入口。
- 整个棋盘区域均可瞄准，包含底部炮口/发射区域：按住拖动持续调整方向，松手发射一次；长按不会自动连发。
- 棋盘稍向下移，保持原有比例，修正横屏时引擎内联尺寸导致的拉伸。
- 一次只跟随一根手指；移出棋盘松手、系统取消、切后台或打开菜单均取消当前手势。飞行中可调方向，不排队补发。
- 阻止网页默认长按菜单。部分小米系统仍会在原地静止长按约两秒后触发系统图片识别；按住后拖动瞄准可正常持续操作，本版保留此系统行为。关闭沉浸模式后恢复原双滑条和发射按钮。
