# Android 5.2.0（预发布测试版）

- 联机各玩家独立随机初盘、后续波次与球序；同难度球数和颜色配额一致。
- 清除球与连带球同步起动、同步渐隐，保持原尺寸；沿确认的加速抛物线散落。普通效果保留细粒和短尾，主棋盘粒子总上限 144。
- “减少消除效果”保留 320ms 基础淡出，关闭粒子、散落和旋转，不再把清除球直接移除；正常发射与首页动效保留。
- 联机普通/沉浸界面沿用其他模式的竖屏 HUD、下一球、棋盘和控件样式，仅增加真实联机状态与紧凑对手信息。
- 正式包名 `com.orbbound.game`，版本 5.2.0 / 50200，沿用发行签名。不要卸载旧应用后再安装；覆盖升级保留数据。

联机需所有参与者使用 5.2.0；旧规则版本会在握手时被拒绝。完整结果以[双端说明](../5.2.0-notes.md)、[验证记录](../5.2.0-validation.md)和[产物清单](../5.2.0-artifacts.json)为准。
