## Android 1.3.0

首次提供可直接安装的 Orbbound 安卓版，支持 Android 7.0 及以上。

- 完整游戏资源随 APK 打包，无需联网。
- 手机顶部信息区、棋盘缩放与触控按钮适配。
- 支持拖动瞄准、松手发射和独立发射按钮。
- 切换后台自动暂停并保存；返回键关闭弹窗、返回首页或最小化应用。
- 保留经典规则、三档难度、本地续局、历史与排行。

下载 `Orbbound-1.3.0-Android.apk` 后在手机打开安装。包名 `com.orbbound.game`，版本号 `1.3.0`，versionCode `10300`，使用专用发行证书签名。校验值见同名 `.sha256` 文件。

验证：16 项自动测试通过、生产构建通过、390×844 手机尺寸页面检查、APK 签名及包信息校验。尚未连接实体安卓手机进行安装实测。

存档保存在应用本地；卸载应用或清除应用数据会删除记录。
