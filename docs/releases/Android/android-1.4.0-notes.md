## 1.4.0 手机版布局与操作更新

- 首页和局内固定单屏，禁止页面上下左右滑动，适配手机安全区。
- 左上集中游戏菜单和暂停；菜单提供设置、历史、重开、返回首页。
- 右上显示下一球和玩法提示。
- 底部固定「逆时针 / 发射 / 顺时针」三个按钮，点按微调 1°，长按连续转动。
- 禁止手机版棋盘拖动瞄准和点击发射，移除独立发射设置。
