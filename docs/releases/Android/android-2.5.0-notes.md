# Android 2.5.0

- 提高实际响度：音效峰值由 0.24 提高至 0.55，增加持续发声段；音乐峰值由 0.035 提高至 0.16，并使用更易听清的三角波。总输出上限提高至 1.6，加入动态压缩控制叠加峰值。音量滑条仍为 0–100%，保留原静音与音量设置；安卓物理音量键控制媒体音量。
- 炮口改为金属筒身、当前球色灯带与方向箭头。炮管与装填球图标跟随角度转动，关闭辅助线也保留炮口。弹道起点沿旋转后的炮管轴线，预览和实际发射共用轨迹。
- 发射键改为按下即发射，支持第二根手指在上条定位或下条微调期间发射，不夺走滑条焦点，不重复触发兼容点击。飞行及结算期间继续禁止重复发射，但可调整下一发角度。
- 性能优化：连续滑动事件合并为每帧一次辅助线更新；相同棋盘、角度及网格偏移复用弹道预测；仅在角度变化时更新读数，缓存滑条触控区域，减少滑动中的布局查询；手机版隔离棋盘绘制范围并移除菜单背景模糊。

验证：71 项自动测试通过，覆盖第二指针发射、持续微调、每帧绘制合并、轨迹缓存失效、炮管旋转、音量与后台暂停；390×844 手机浏览器外观检查；Android release 构建、原签名验证。尚未进行实体手机双指操作及试听，未宣称实测帧率提升。
