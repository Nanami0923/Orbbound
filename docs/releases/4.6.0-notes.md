# Orbbound 4.6.0 · 联机流畅度与棋盘统一（测试版）

Android 与 Windows 同步更新。本版统一棋盘外观、默认 60 FPS，修复房主动画时间阶梯，并调整联机暂停和地址入口。以 prerelease 测试版发布，4.3.0 正式版继续保留；性能实测范围与未完成矩阵见[验证记录](4.6.0-validation.md)。

## 棋盘与帧率

- 联机竞分、对战与三种单机共用球体、场地、炮台、瞄准和基础效果定义。主棋盘使用同一皮肤，对手小图保留紧凑布局。
- Windows 删除炮口右侧独立“当前球”文字和球副本，保留炮口中的球及右侧下一球。
- 删除自动帧率档，新安装、旧自动设置和恢复默认均为 60 FPS；手动 30 / 60 / 90 / 120 保留。合法旧手动选择不会被强制重置。
- 去掉根据负载和 rAF 估值自动升降帧档的路径，独立自动画质保留。实际帧率仍受设备、系统和负载影响；静止省电状态与活动绘制分别显示。
- 房主和客人使用连续展示时钟，动画不再依赖房主每 50ms 的规则批处理阶梯。规则时间、可发射时刻、计分与攻击不因展示插值改变。
- 缓存球体、静态棋盘及消除过渡数据，按玩家更新画面；观察层纳入统一预算，减少多人无关绘制。
- 修复结束动画定时器提前唤醒时，偶尔停在 `0:00` 而不进入联机结算页的问题；下一球预览跟随实际绘制阶段更新。

## 暂停与房间地址

- 删除每人每局成功暂停次数上限，以及整局累计 120 秒暂停预算。
- 同一选手的“暂停”和“设置”共用 15 秒申请间隔：成功后从比赛实际恢复时起算，拒绝、取消或投票过期从结果确定起算。冷却中重试不会延长截止时间。
- 全员投票最多等待 10 秒，单次暂停最多 60 秒，设置关闭确认与准备恢复继续保留；掉线恢复是独立机制。
- 房主大厅首屏直接提供实际 `IPv4:端口` 复制栏，多网卡可切换；复制失败时保留手动选择复制。
- 加入默认显示地址输入栏，直连无需等待附近扫描；附近、最近与诊断入口继续保留。

**暂停规则已改变，所有选手须统一使用 4.6.0。** 消息封装仍为 v3，规则指纹更新为 `4e2a4139`，会明确拒绝 4.5.0 等旧联机规则，不支持混用。旧单机存档及历史记录仍可读取。
