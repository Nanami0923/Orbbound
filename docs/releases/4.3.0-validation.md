# 4.3.0 验证记录

日期：2026-10-15。版本范围为方案 P0「双人同图竞分」。本记录将真实套接字、开发环境界面模拟和设备验证分别记录。

## 共用逻辑与界面

- Vitest：29 个文件、256 项通过，其中新增权威规则 21 项、会话 27 项、联机控制 14 项；原有 194 项回归全部通过。
- 同种子波次、计分与平局裁决、时间下压、触底封盘、输入冷却、序号去重、棋盘版本、超时/认输结算均有规则测试。
- 会话测试覆盖握手与准备、双人开局、暂停/恢复、掉线与重连、再来一局、取消连接、后台禁止开局、旧对局消息回放和旧 epoch 输入拒绝。房主按单调时钟裁决，客户端预测不提交最终成绩。
- 输入测试覆盖键盘、双滑杆、多指、pointercancel、越界松手、暂停/弹层、沉浸手势和动画期间冷却边界。
- CUA 操作实际开发页面的两个 iframe（390×844 与 320×568），通过明确标识的 BroadcastChannel 模拟传输，完成创建、发现、加入、双方准备、同步倒计时、各发射一次、请求/同意暂停、双方恢复、主动退出、对方认输结算。结算显示双方各发射 1 次。
- 320×568 实测主棋盘容器约 250.94×297.98 CSSpx，对手缩略图独立排列，发射按钮和暂停入口可达。极端安全区允许纵向滚动。这个尺寸检查不等于 Android dp 或真机触摸验收。
- 联机界面使用独立 Canvas 展示共用纯规则的权威快照，避免重用单机场景时写入单机存档；沿用已有音效与输入工具。

## Windows 原生网络

- .NET Framework 原生网络测试 74 项、桥接来源校验 12 项、既有外壳策略 15 项通过。
- 使用真实 TCP / UDP 回环套接字验证 4 字节大端长度帧、中文/UTF-8、分片与合并帧、超长帧拒绝、连接关闭、发现应答、队列与资源释放。
- 额外复现并修复 Windows UDP ICMP PortUnreachable 引发接收线程退出的问题；回归验证关闭查询端后，房主仍可回应新客户端。
- WebView 桥接限定当前 WebView 的 `https://orbbound.local` 来源；重载后旧回调失效，异步事件经 UI 线程传递，队列设限。

## Android 与跨语言互通

- JDK 21 下 Android Java 编译及 13 项 JUnit 通过（9 项新增网络测试与 4 项既有文件测试）。
- 实际运行 Java `LanTcpService` 与 C# `LanService`：Java 作服务器、C# 作服务器两种方向均通过；每方向双向各 44 帧，共 176 个有效载荷，包含中文、emoji、60 KB 文本、精确 65536 字节帧、连续 40 帧及关闭通知。
- 上述是桌面上的真实 Java / C# 网络服务互通，不是 Android APK 与 Windows EXE 的跨设备实测。
- Android 原生插件按 Activity 生命周期报告前后台，网络服务使用 Wi-Fi / 以太网及接口回退，不依赖互联网可用性。保持 targetSdk 36。

## 未覆盖条件与边界

- 未完成 Android 真机安装、Android—Windows / Android—Android 实机对局、热点房主、Wi-Fi 广播隔离、系统后台回收、权限/防火墙提示及长时间耗电验收。开发期间 ADB 起初无设备，发布前检查发现已有在线设备；本轮未对其安装或开展成对对局测试。
- Windows 原生联网组件经过编译和真实套接字测试；本次未把浏览器 UI 模拟写为 Windows EXE 全流程验收。
- 初版仅 IPv4、两人、同一可互通局域网；没有公网中继、主机迁移、四人房间、聊天、攻击对战和协作接力。
- 对局中房主进程消失或超出恢复窗口，按中断处理，不伪造胜负；未实现跨进程重启恢复比赛。已结束结果保存在联机记录，与单机排行隔离。主动离开方立即返回首页，不保证收到离开后的最终快照。
- 联机记录最多保留 100 条，目前不纳入既有单机 JSON 备份；网络传输为受信任局域网 TCP，不提供互联网级身份认证或加密。
- 部分设计细项留待后续：发现列表不显示完整人数/平台标签、没有二维码加入、没有故障诊断导出。开发模拟入口仅存在开发构建。

```powershell
npm test
npm run package:win
$env:JAVA_HOME='C:\Program Files\Java\jdk-21'
$env:ANDROID_HOME='C:\Users\10641\AppData\Local\Android\Sdk'
.\android\gradlew.bat -p android testDebugUnitTest
node scripts/test-lan-interop.mjs

```
