# Orbbound Android 5.2.1（预发布测试版）

修复部分手机因有效显示宽度较小，首页模式入口退成单列、下方入口难以看到的问题。Android 首页四个模式固定为 **2×2**：闯关、无尽在上，限时、局域网联机在下。

- 取消小于等于 340 CSS 像素时切为单列的行为。
- 小于等于 360 CSS 像素时收紧卡片内部图标列、列间距和左右留白，保留图标、标题、存档与分数信息。
- 短屏继续使用独立内容滚动区，底部玩法、设置、记录入口保持可达。首页循环演示及 5.2.0 消除动效继续保留。
- Android 版本独立为 `5.2.1 / 50201`；Windows 继续使用 5.2.0，本次仅提供 Android APK。

沿用正式包名与发行签名，可从 Android 5.2.0 覆盖安装保留数据。联机消息、规则与内容未变，可继续与 Windows / Android 5.2.0 联机；不能与 5.1 / 4.7 等旧规则版本混连。

634 项共用测试及 49 个浏览器布局场景通过，Android 实机完成四个模式入口、底部入口和原签名升级验收。升级前后的现有无尽存档与设置逐值一致。样例已由用户确认。

详细范围见[验证记录](5.2.1-validation.md)，安装包大小和 SHA-256 见[产物清单](5.2.1-artifacts.json)。
