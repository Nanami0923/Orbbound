# Orbbound Windows 1.4.0

同步 Android 2.0.0–2.3.0 的功能，保留 Windows 鼠标与键盘操作。Windows 独立版本号为 1.4.0，Android 保持 2.3.0。

## 游戏功能

- 首页分为无尽与限时模式；限时可选 5 / 10 分钟及简单、普通、困难三档难度。
- 限时模式分别显示次数和时间两条下落倒计时，任意一项归零后下降并同时重置；整局剩余时间单独显示。间隔随有效游玩进度缩短：简单 36→18 秒、普通 30→15 秒、困难 24→12 秒。
- 无尽与限时各保留一局独立存档，退出后可继续；存档、打开菜单及切后台会冻结进度，临时存档不入榜。右侧新增主动结算入口。
- 结算成绩按简单 ×1、普通 ×1.5、困难 ×2 加权，分无尽、限时 5 分钟、限时 10 分钟三个榜单。重开只记录放弃，不入榜；点击标题切换排行榜与历史记录。
- 鼠标移动瞄准、点击发射；方向键点按微调、长按平滑加速；Q / E 快转 30°，空格发射。也可使用左侧对应按钮，快转保留平滑过渡及 ±78° 角度限制。
- 飞行和棋盘下落期间仍可转向，长按不中断；下落时显示方向短线，落定后恢复完整辅助线。发射仍等待动画完成。
- 保留炮口右侧放大的下一球提示，去掉右侧栏重复预览；结算标记居中、提示按标点分行，小窗口下完整显示操作区。

## 两种交付方式

1. **完整游戏目录**：`win-unpacked/`，双击其中的 `Orbbound.exe`。必须保留整个目录。下载用 `Orbbound-Windows-1.4.0-x64.7z`。
2. **单文件便携版**：`Orbbound-Windows-1.4.0-Portable-x64.exe`。只需分发这一个 EXE，无需安装或联网；启动时自动将内置 Electron 运行库解压到临时目录，正常退出后清理。首次启动及每次解压比目录版稍慢。

两种形式均面向 Windows 10 x64。存档和设置仍保存在 `%APPDATA%/orbbound`，与之前 Windows 版本共用；不会写进临时运行目录。EXE 未做发行者数字签名。

## 构建与版本管理

- `npm run package:win` 同时生成目录、7z 和单 EXE，输出到 `最终交付/Windows/Orbbound-Windows-1.4.0/`。
- Windows 网页构建输出 `.build/windows/web/`，默认 / Android 输出 `dist/`，避免平台版本和资源混用。
- 源码沿用共用规则和存储实现；本次一并纳入已完成的本地目录整理，历史成品没有重新构建。

验证记录：61 项自动测试通过，覆盖双模式倒计时、存档、加权计分、桌面按键重复事件、松键停止、快转和下落中转向；1280×800 与 900×540 浏览器桌面布局检查通过，实测限时存档刷新后恢复、主动结算及独立历史记录。目录版与便携 EXE 均在隔离测试数据目录中启动成功，未发现致命运行错误；7z 与 EXE 内嵌归档完整性检查通过。未做多设备帧率基准测试。
