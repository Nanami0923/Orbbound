# Orbbound 1.2.0 · 泡泡消除

Windows 10 64 位目录版。进入 win-unpacked，双击 Orbbound.exe 启动。无需安装开发环境或联网，请保留整个游戏目录。

## 本次修复

- 棋盘下降时同步六角网格的奇偶行偏移，保留已有小球的横向位置和相邻关系，修复乱序、浮空及后续误掉落。
- 棋盘下降动画完成前不能再次发射，避免显示位置与碰撞位置不一致。
- 新局恢复动画系统和计时器，修复暂停后换难度、独立发射模式下小球停住的问题。
- 连续按住空格不会重复发射或误触其它按钮。
- 文案改为“瞄准、同色消除、悬空掉落”。三个相邻同色球会消除；失去顶部支撑的小球不分颜色掉落，这是正常规则。
- 难度显示为简单·漫游、普通·经典、困难·风暴，并说明颜色数、初始行数和首次下降前发射次数。
- 危险程度改为“距离棋盘下降：再发射 N 次”，最后一发提示“下一发后下降”。原难度节奏未更改，漫游、风暴可能因累计余量出现相邻周期相差一次的情况，倒计时会按实际值计算。

## 旧版数据

历史成绩、排行榜、设置继续保留。旧版未完成棋盘缺少可靠的行偏移信息，可能已经出现错位，因此不加载到新规则中；首页会明确提示，请开始新局。旧版本文件夹未删除。

## 验证

15 项自动测试通过，覆盖同色匹配、悬空检测、奇偶行邻接、下降前后位置保持、倒计时、暂停换局与下降动画期间输入锁定。
60 组固定随机开局、超过 1,000 次发射的规则回归检查通过。
已在同一构建的网页界面复测“开启独立发射 → 返回首页 → 漫游 → 空格发射”，正常结算并恢复操作。
