# Windows 4.6.0（测试版）

- 修复联机结束动画偶尔停在 `0:00` 的定时器边界，下一球预览跟随实际绘制阶段。

- 删除截图所示炮口右侧“当前球”文字及独立球副本，保留炮口球和右侧下一球。
- 联机与三种单机共享棋盘视觉资源与绘制定义，保留多人信息和只读观战。
- 默认 60 FPS，移除自动帧率与隐式负载降档，保留手动 30 / 60 / 90 / 120；旧合法手动值保留。
- 暂停不限次数，取消整局累计 120 秒预算；同一选手的暂停与设置共用 15 秒申请间隔，单次 60 秒与最多等待 10 秒的全员投票继续保留。
- 大厅首屏可复制实际房间地址；加入默认地址输入，保留附近与最近入口。

完整解压 ZIP 后运行 `Orbbound/Orbbound.exe`；运行环境和数据目录沿用，旧存档及备份迁移保留。

联机请全员升级至 4.6.0，不能与 4.5.0 混用；消息封装仍为 v3，规则指纹为 `4e2a4139`。本版为 prerelease；原生、DPI 与联机验证范围见[验证记录](../4.6.0-validation.md)。
