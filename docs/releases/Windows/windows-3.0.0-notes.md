# Orbbound Windows 3.0.0

Windows 与 Android 版本统一为 3.0.0，同步通用功能，沿用 Windows 鼠标与键盘操作。

- 首页改为左右分栏：标题与玩法说明在左，动态演示与模式卡片在右。每种模式合并显示存档、最佳成绩与继续入口，另提供新游戏入口。
- 动画从中心依次向左右发射；左侧同色消除，右侧同色消除后失去支撑的球掉落。使用少量球，不绘制分支连接，也不穿过其他球。
- 同步首页、游戏和后台切换的连续音乐与独立音符淡出修复，以及掉落重力表现、危险线和中性瞄准点。
- 保留鼠标瞄准/点击发射、方向键转向、Q/E 快转、空格/按钮发射，以及桌面当前球、下一球提示。安卓系统栏、触控双滑条、按键位置和震动属于手机功能。
- 版本一致性纳入自动测试与 Windows 打包检查，避免两端版本号再次分离。

交付包括单文件便携 EXE、完整运行目录 7z 及 SHA-256 校验文件。支持 Windows 10 x64，存档仍位于 `%APPDATA%/orbbound`，与旧 Windows 版共用。单 EXE 未做发行者数字签名。

验证：15 个文件、92 项自动测试通过，Windows 生产构建通过。在隔离存档目录中检查实际 Electron 成品的 1280×800、940×544 窗口，首页无溢出；空格发射、无尽/限时 10 分钟续玩、新游戏入口及桌面设置检查通过，未出现页面运行异常。便携 EXE 独立解压启动，并成功读取目录版测试存档；EXE 内嵌归档和完整目录 7z 均通过完整性校验。Android 同源 release 构建和 v2/v3 签名校验通过。

截图和测试数据保存在本地 `artifacts/3.0.0/`，不上传个人数据。未进行 Windows 外部录音波形分析或多设备帧率基准测试。
