# Windows 4.5.0（测试版）

修复首页选择区域的大圆角裁切模式卡边角和按钮，模式卡独立绘制边界；按实际 CSS 客户区重新分配首页高度。普通短菜单自然收紧，教程和长内容采用有界分页，设置分类首页保持紧凑，仅详情正文纵向滚动。窗口变窄时继续保留桌面键鼠操作。

分页不再永久拆散原步骤；设置修改按实际变更分派，减少无关刷新率请求、画布重建和输入重绑。联机桥接增加超时、退出与会话隔离，场景未就绪时的返回和取消也增加保护。尚不能据此宣称所有卡死现象均已解决。

[下载 Windows 4.5.0 ZIP](https://github.com/Nanami0923/Orbbound/releases/download/v4.5.0/Orbbound-Windows-4.5.0-x64.zip)。完整解压后运行 `Orbbound/Orbbound.exe`，需要 .NET Framework 4.8 和共享 WebView2 Runtime；不附带运行环境安装包。数据目录及「设置 → 数据与维护 → 导入旧 Windows 存档」入口保留。

共用 439 项测试、Windows 打包及 125 项原生检查通过。Windows 模式在 1280×720、640×360、800×600、1366×768、1920×1080 五个 CSS 视口的入口边界、中心和模式卡边角命中检查通过。

原生启动的可访问性状态确认版本为 4.5.0，并读到旧存档；截图出现 `FrameArrived` 超时且输入几何不可用，**未完成原生视觉、所有最小窗口和 DPI 组合验收**。浏览器 CSS 视口检查不替代这些项目。

**本版标为 prerelease 测试版，[4.3.0 正式版](https://github.com/Nanami0923/Orbbound/releases/tag/v4.3.0)继续保留。** 局域网协议仍为 v3；4.4.0 混用尚未验证，建议全部成员使用 4.5.0，真实混合设备联机及长时间稳定性范围见验证记录。
