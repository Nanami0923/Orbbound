# Orbbound Windows 1.5.0

- 交换球色提示位置：左侧显示“下一球”，炮口右侧显示“当前球”。开启或关闭瞄准辅助时均保留提示，发射后随球序更新。
- 移除桌面左转、右转及两个 30° 快转按钮，保留发射按钮。鼠标瞄准、点击发射、方向键长按加速、Q / E 快转及空格发射保持可用。
- 保留无尽 / 限时模式、双倒计时、独立存档、主动结算及加权排行榜。Android 仍为 2.3.0，移动端提示位置和触摸按钮不变。

## 交付

- 完整游戏目录：`win-unpacked/`，运行其中的 `Orbbound.exe`，请保留整个目录。
- 单文件便携版：`Orbbound-Windows-1.5.0-Portable-x64.exe`。完整游戏和 Electron 运行库均内置，无需安装或联网；运行时自解压至临时目录，正常退出后清理。
- 完整目录压缩包：`Orbbound-Windows-1.5.0-x64.7z`。

支持 Windows 10 x64。两种形式共用 `%APPDATA%/orbbound` 中的存档和设置；临时目录清理不删除存档。EXE 未做发行者数字签名。

验证：61 项自动测试通过，Windows 构建通过；检查 1280×800、900×540 桌面布局，以及关闭辅助线、发射前后的球色提示。目录版与便携版均在隔离数据目录中成功启动，无致命运行错误；压缩包与 EXE 内嵌归档完整性校验通过。未做多设备帧率基准测试。
