# Orbbound 1.1.0 · Windows 10 64 位

打开 win-unpacked 文件夹，双击 Orbbound.exe 即可运行。无需安装 Node.js，也无需联网。
移动或分享游戏时，请复制整个 win-unpacked 文件夹，不要单独复制 EXE 或删除其中的 DLL、resources、locales。

## 本版更新

- 棋盘随窗口高度缩放，完整居中；左侧为分数、危险条、计时与当前棋子，右侧为下一枚、说明和操作。
- 关闭瞄准辅助后，发射器变为短方向线，棋盘内隐藏光标。鼠标移动瞄准、点击发射；方向键微调、空格发射。
- 独立发射模式会显示单独的发射按钮。
- 历史记录保存最近 500 局；完成对局按分数取前 10 名，同分优先用时较短者。记录开始时间、难度、结果、分数、发射次数和用时；暂停期间不计时。
- 重开会保存上一局的历史，但不参与排行榜；返回首页或退出可保存当前进度供下次继续。
- 旧版没有记录过的对局无法补回。

## 数据与体积

本机数据保存在当前 Windows 用户的 AppData/Roaming/orbbound 中，不上传网络；复制游戏目录不会自动带走个人存档。备份个人数据时，请先关闭游戏，再备份该数据目录。

本版游戏目录约 252 MB，旧目录约 428 MB，减少约 41%（均为未压缩目录）。游戏资源约 1.5 MB，其余主要是独立运行所需的桌面运行库。

内存优化包括共享棋子纹理、限制 60 FPS、首页停止游戏循环、有界历史记录、减少轨迹计算的临时对象。内存仍会随显卡、窗口尺寸和对局变化，不承诺固定上限。
