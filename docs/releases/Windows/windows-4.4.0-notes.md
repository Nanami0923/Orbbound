# Windows 4.4.0（测试版）

同图竞分与连锁对战均支持 2–4 人，Windows 和 Android 4.4.0 都可建房。暂停申请会在所有在赛玩家当前页面显示；全员同意后才能调整设置，完成并全员准备后倒计时恢复。

联机改用桌面布局和单机一致的操作：鼠标左键或右键按住瞄准、松开发射，保留键盘微调及可配置快捷键。联机不再显示手机双滑杆控制栏。三种单机与两种联机统一状态、设置和主要操作区域。

连锁对战按其他存活选手的合计消除量产生来袭：2 / 3 / 4 人阈值为 12 / 24 / 36 球；自己的 12 球可抵消一行。新增多人排名、弃权与出局观战，详细规则见[完整更新说明](../4.4.0-notes.md)。

首页四入口采用 2×2 排列，选关、记录、教程与普通弹层改用分页或分步；只有设置详情允许上下滚动。设置统一为声音与音乐、操作与辅助、画面与性能、数据与维护四类。旧版存档迁移入口更新为「设置 → 数据与维护 → 导入旧 Windows 存档」。

[下载 Windows 4.4.0 ZIP](https://github.com/Nanami0923/Orbbound/releases/download/v4.4.0/Orbbound-Windows-4.4.0-x64.zip)。完整解压后运行 `Orbbound/Orbbound.exe`，需要 .NET Framework 4.8 和共享 WebView2 Runtime；不附带运行环境安装包。联机协议为 v3，所有玩家必须更新至 4.4.0。默认 TCP 42171 / UDP 42170，连接时以房间显示的实际地址为准。

共用测试及 125 项 Windows 原生检查通过，并完成桌面 Java / C# 四进程双向房主互通和浏览器四端流程检查。**本版没有实体手机在线，实体四设备矩阵及 20 局真人试玩尚未完成。** 桌面互通和浏览器模拟不等同于 Windows ↔ Android 真机验收，因此以测试版发布；[4.3.0 正式版](https://github.com/Nanami0923/Orbbound/releases/tag/v4.3.0)继续保留。
