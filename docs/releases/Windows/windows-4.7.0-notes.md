# Windows 4.7.0（测试版）

- 修复窄屏结算“再开一局”文字与箭头重叠：文字与箭头使用独立列，窄屏主操作独占一行。
- 首页左侧演示球与两球同时相切，路线及弹丸使用同一落点。
- 单机结算页顶部关闭、底部首页、Esc 和允许的遮罩关闭统一回首页；菜单设置/历史、关卡详情及模式排行按来源返回并保留参数。
- 标题和按钮使用对称空间居中，快捷键、图标和箭头保留独立位置。
- 联机与三种单机共用同档位下一球组件；联机时间、延迟、状态、操作及对手信息重新分组，保留桌面鼠标、键盘和只读观战。
- 终局首次成功记录保持不变；保存或清理失败有真实提示与重试，保留可恢复副本，阻止已结算旧检查点重新续玩。

游戏内结果页关闭返回首页；Windows 系统标题栏关闭仍退出应用。完整解压 ZIP 后运行 `Orbbound/Orbbound.exe`，继续使用系统 .NET Framework 4.8 和共享 WebView2 Runtime；旧数据目录及备份迁移入口保留。

沿用联机消息 v3、规则指纹 `4e2a4139` 和内容指纹 `f942c2f9`。4.6 / 4.7 双向混连已通过同机生产 C# 服务与真实游戏会话测试；这不等同于原生窗口视觉、DPI 或完整实体终端矩阵通过。4.5.0 等旧规则版本仍不能加入。

本版保持 prerelease，4.3.0 继续为稳定正式版。原生启动、视觉、输入及 DPI 的实际验收范围见[验证记录](../4.7.0-validation.md)。
