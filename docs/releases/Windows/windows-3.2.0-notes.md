# Windows 3.2.0

- 去掉左侧发射按钮和下一球卡片；左侧保留得分、下降倒计时和本局用时。
- 下一球移到右侧顶部，存档与其他选项集中在右侧，合并为「存档并返回」。按钮旁显示实际快捷键。
- 玩法提示说明鼠标左键、右键或空格发射；更改发射键后，提示自动使用新按键。
- 「设置 → 键盘快捷键」可修改发射、转向、快转、存档、结算、重开、设置、记录和玩法提示的按键。支持字母、数字、方向键、空格、Enter、Esc；禁止重复绑定，重启和备份导入后保留。F11 固定切换全屏。
- 修复进场音频延迟：本地 Windows 外壳允许游戏音频立即启动；音频恢复完成后立即调度，关闭未使用的 Phaser 音频管理器。保留音乐音量、加速开关和切换淡出。

默认快捷键：空格发射；← / → 转向；Q / E 快转；Esc 存档并返回；F 结算；R 重开；S 设置；H 记录；I 玩法提示。

[下载 Windows ZIP](https://github.com/Nanami0923/Orbbound/releases/download/v3.2.0/Orbbound-Windows-3.2.0-x64.zip)。沿用轻量外壳，不包含运行环境；完整解压后运行 `Orbbound/Orbbound.exe`。从 3.1.0 升级直接使用原数据目录；3.0.0 及更早 Electron 版可通过设置中的旧版存档迁移功能导入。
