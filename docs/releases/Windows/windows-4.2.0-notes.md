# Windows 4.2.0

增加最高 120 FPS 自适应、画面清晰度和实际帧率显示；补弹窗焦点、防误重开、方向键组合、全屏入口和 WebView2 故障恢复。完善失焦/最小化/锁屏/睡眠保存与挂起，禁用浏览器专属快捷键。

共用玩法增加实操练习、有效颜色供球、规则分榜、星级预算与成绩反馈；旧进行中对局保留原规则，旧纪录可继续查看。

继续使用 .NET Framework 4.8 与共享 WebView2，完整解压后运行 `Orbbound/Orbbound.exe`；不附带运行环境安装包。
