# Orbbound Windows 1.6.0

同步 Android 2.4.0 / 2.5.0 的非操作方式更新：

- 递增计分与悬空额外奖励：同色消除 3 / 4 / 5 / 6 球得 30 / 50 / 80 / 120 分；悬空 1 / 2 / 3 球额外得 30 / 70 / 120 分。难度系数不变，旧成绩保留且不追溯重算。
- 音量滑条代替音效开关，同时调节音效与新增的本地循环 BGM，0% 静音。提高峰值与持续发声响度，加入动态压缩；兼容旧静音设置，后台暂停音乐。
- 炮管、球色灯带、方向标记及装填球图标随角度转动，关闭辅助线仍显示炮口。弹道与炮管轴线对齐。
- 等间距轨迹点、反弹标记、实际大小落点圈；同一帧合并瞄准更新，相同棋盘与角度复用轨迹预测，减少重复计算和读数刷新。
- 移除减少动态效果选项及相关功能。

操作保持 Windows 方式：鼠标瞄准 / 点击发射、方向键长按转向、Q / E 快转 30°、空格或发射按钮发射。不启用手机双滑条及左右位置调换。保持 Windows 1.5.0 的左侧下一球、炮口右侧当前球提示。

交付：单文件便携 EXE、完整 win-unpacked 目录及 7z 压缩包、SHA-256 校验文件。存档继续使用 %APPDATA%/orbbound。EXE 未做发行者数字签名。

验证：73 项自动测试、Windows 生产构建、桌面布局及操作检查、发布归档完整性检查。未进行多设备帧率或实际扬声器响度测试。
