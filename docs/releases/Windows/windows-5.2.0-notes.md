# Windows 5.2.0（预发布测试版）

- 联机各玩家独立随机初盘、后续波次与球序，棋盘与供球随机流分离，重连保留原权威状态。
- 直接消除与连带掉落共用 720ms 加速抛物线和渐隐过程，球体不缩小。增加细粒与短尾，主棋盘粒子总上限 192。
- “减少消除效果”保留 320ms 原位淡出，关闭粒子与散落；正常发射、装填和普通界面动效保留。
- 联机采用其他模式的左侧信息、中间棋盘、右侧操作框架，共用 HUD、下一球和按钮基础样式。联机信息与对手区作为增量，保留真实暂停投票和认输规则。
- Windows 原生程序版本 5.2.0.0。完整解压后启动 `Orbbound/Orbbound.exe`，使用系统 .NET Framework 4.8 与共享 WebView2 Evergreen，数据继续保存在 `%LOCALAPPDATA%/Orbbound`。

联机需所有参与者使用 5.2.0；旧规则版本会在握手时被拒绝。完整结果以[双端说明](../5.2.0-notes.md)、[验证记录](../5.2.0-validation.md)和[产物清单](../5.2.0-artifacts.json)为准。
