# Windows 5.1.0（预发布测试版）

- 延续深海军蓝、低高光的哑光球面视觉，保留原球面图案；首页布局与双端一致的模式和预览层级同步更新。
- 左侧下压进度与限时信息区增加轨道和分隔线之间的留白，保留真实倒计时、数值和进度比例。
- 清除动画中直接消除球和连带下落球从同一命中时刻开始运动；玩法结果与既有输入锁不变。
- 保留现有鼠标/键盘操作、局域网规则和 Windows 运行环境要求。

Windows 原生检查 125 项通过。原生单局胜利样本以 17 次发射得到 5,250 分和 3 星；单局失败样本发射次数耗尽于第 22 次发射、得到 0 星。

4.7 → 5.1 和 5.1 → 4.7 双向真实会话及同机生产 C# 服务自然终局通过。物理 LAN 四人局也通过：Android 实机房主、Windows 打包原生 guest、同机两个生产 C# headless guest；全员暂停/恢复、手机观战后返回、Windows 原生输入 47 轮、自然结算通过，Android 与 Windows UI 均显示 690 / 660 / 30 / 30 的一致排名分数。该验证包含两个实体 UI 设备、四个实际参与者，不是四台独立实体设备。

尚未完整覆盖所有 Windows 系统 DPI、低性能设备、四台独立实体终端和长时运行升温场景；浏览器截图不作为 Windows 原生窗口视觉或 DPI 证据。完整设备、窗口配置和兼容性范围见[验收记录](../5.1.0-validation.md)。

本版为 prerelease 测试版，稳定正式版仍为 4.3.0。双端变更总览见[5.1.0 更新说明](../5.1.0-notes.md)，包体校验值见[产物清单](../5.1.0-artifacts.json)。
