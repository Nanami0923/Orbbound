# Orbbound 5.1.0（预发布测试版）

5.1.0 延续尚未公开发布的 5.0.0 界面改造候选，并按真机与界面审查反馈修正双端排版和动效。**5.0.0 没有公开发布记录**；稳定正式版仍为 4.3.0。本版继续使用深海军蓝、低高光和哑光球面风格，保留原有球面图案。

## 界面与动效

- Android 闯关流程按“章节选择 → 单列关卡列表 → 单关详情”分层。章节、关卡行和详情统一应用内面板风格；保留章节进度、星级、锁定校验、真实存档续玩、棋盘预览和关卡规则。
- Android 首页模式卡改为左侧图标与右侧文字组并列，图标对齐文字组中心，缩短常驻说明并提高关键文字字重。关卡/星级进度、最高纪录、续局分数、限时 5/10 分钟入口和联机人数信息仍由真实状态提供。演示融入透明背景并保留循环与原球面图案。
- 调整 Android 单机和联机下一球预览，使预览盒、球体和图案有一致的安全边界；不改变球体图案及发射、装填、观战时的实际颜色。
- Windows 左侧下压/限时信息区增加轨道与分隔线之间的留白，保留真实进度比例和计时读数。
- 双端清除动画中，直接消除与连带掉落球从同一命中时刻开始各自轨迹；保留原有计分、棋盘变化、发射锁和联机权威就绪时序。
- 备份导入对历史记录的 `elapsedMs` 保持有限非负数校验，允许合法的浮点毫秒值，避免拒绝真实运行中产生的时间值。

玩法规则、计分、随机序列、联机权威规则和存档数据结构保持现有规则。版本基线和升级迁移的实际验证结果见验收记录。

## 验证范围

- 共用自动测试：58 个文件、619 项全部通过；Android JVM 测试 22 项通过；Windows 原生测试 125 项通过。
- Windows 原生单局胜利样本：17 次发射、5,250 分、3 星；单局失败样本：发射次数耗尽于第 22 次发射、0 星。不是多局聚合统计。
- Android 实机操作完成 4 次实际发射并记录到 3,160 分；章节、关卡列表、详情三级界面通过本轮检查。
- 4.7 → 5.1 与 5.1 → 4.7 的双向真实会话及同机生产 C# 服务自然终局通过。5.1 物理 LAN 四人局也通过：Android 实机房主、Windows 打包原生 guest、同机两个生产 C# headless guest；全员暂停/恢复、手机观战后返回、Windows 原生输入 47 轮及自然结算通过。Android 与 Windows 两个 UI 的名次分数一致，分别为 690 / 660 / 30 / 30。
- 该 LAN 样本有两个实体 UI 设备和四个实际参与者，不是四台独立实体设备。Android 正式包同签名覆盖升级后原存档和设置一致；含真实历史的四项内置备份导入/导出一致，原 `.lantest` 的全部八项键值恢复保留。
- 5.1 沿用 4.7 的联机消息封装 v3、规则指纹 `4e2a4139` 和内容指纹 `f942c2f9`，未改变混连规则。

尚未完整覆盖系统 DPI 配置矩阵、低端设备、四台独立实体终端和长时间运行升温测试；浏览器、同机 C# 服务与自动测试均不替代这些实机范围。各项证据与限制以[5.1.0 验收记录](5.1.0-validation.md)和[产物清单](5.1.0-artifacts.json)为准。
