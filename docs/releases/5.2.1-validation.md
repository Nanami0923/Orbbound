# Android 5.2.1 验证记录

验收日期：2026-10-23。基线：5.2.0 源码 `1870b63`。本轮仅修复 Android 首页四个模式的排列与窄屏间距，并拆分 Android 版本和发布链路。

## 页面与交互

Playwright / Microsoft Edge 移动触屏视口共 49 个场景通过，未记录页面异常：

- 43 个常规视口：宽度 320、327、340、341、360、393、400、412，分别搭配高度 480、568、616、700、869；另含 568×320、869×400 横屏及 600×960 平板竖屏。
- 3 个 CSS 150% 文字压力场景：320×568、327×616、400×869。此项放大卡片和底部按钮字号，不等同 Android 系统字体缩放验收。
- 3 个恢复本轮升级前真实存档与设置的隔离浏览器场景：327×616、320×568、400×869。

每个场景检查四卡为两行两列、顺序正确、图标与文字不重叠、卡片内容不横向溢出、底部栏位于视口内且不与内容区重叠；四卡滚动后均能命中。480 高短屏及部分横屏保留内容区少量滚动，未通过遮挡或删减模式入口强行塞入首屏。

Android 16 实机的隔离验收应用为 `com.orbbound.game.lantest`，安装版本 `5.2.1 / 50201`。实际 WebView 视口 400×869、DPR 3，卡片两列各 184px、两行各 126px。四模式入口及玩法、记录、设置均完成打开与返回，未记录页面异常；返回首页后仍有 8 个循环演示动画在运行。首页和窄屏样例已获用户确认。
