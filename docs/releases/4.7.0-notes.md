# Orbbound 4.7.0 · 排版与关闭返回（测试版）

- 修复窄屏结算“再开一局”文字与箭头重叠：文字与箭头使用独立列，窄屏主操作独占一行。

Android 与 Windows 同步更新。本版完成界面与返回流程修整，保留 4.6.0 的固定帧率、联机规则与展示时钟。保持 prerelease 测试版，4.3.0 继续为稳定正式版；实际验收范围见[验证记录](4.7.0-validation.md)。

## 界面与返回

- 首页左侧演示球准确落在两球中间下方，同时贴合两球；路线与弹丸共用落点，保留重播及减少动态效果。
- 强制结算及其他单机终局页的顶部关闭、底部首页、Esc、Android 返回和允许的遮罩关闭统一返回首页。关卡详情、取消确认、菜单设置/历史和模式排行按来源返回，保留筛选、页码及模式参数。
- 标题与按钮文字采用对称空间居中，图标、箭头和快捷键单独布局；表单与长文继续保持易读对齐。
- 联机与闯关、无尽、限时共用同平台、同布局档位的下一球组件；飞行中、装填后和观战切换时跟随实际展示状态。
- 联机顶部将时间、延迟、状态和操作分组；对手区按人数和屏幕尺寸布局，减少窄列断字、固定空槽与多余空白。普通菜单继续分页，设置详情保持单一滚动区。

## 记录与保存保护

同一局首次成功保存的终局记录保持不变，重复离开或重试不再改写结束时间与排名。保存和清理结果分别反馈；必需写入失败时保留内存终局与可恢复存档，提供重试，重开或放弃不会绕过失败继续清除。已成功结算但未清理的旧检查点也不能被当作未结束游戏续玩。

模拟写入/删除失败、导航来源与旧回调保护已有自动回归；这不代表真实设备存储故障、所有异步时序或完整设备矩阵均已验收。

## 联机与旧数据

消息封装 **v3**、规则指纹 **`4e2a4139`**、内容指纹 **`f942c2f9`** 均沿用 4.6.0。同机生产 C# 服务搭配真实游戏会话，已通过 4.6 房主 / 4.7 客人及反向混连；不将此结果扩大为所有实体设备混连通过。4.5.0 等旧规则版本仍不能加入。

旧存档、设置、记录与备份继续兼容。默认 60 FPS、手动 30 / 60 / 90 / 120、独立自动画质、暂停申请冷却与地址优先加入均保持。
