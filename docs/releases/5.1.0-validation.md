- 最终重新打包后再次原生启动，核对版本、首页、球面图案，进入无尽新局真实发射一次，下压倒数由 10 变 9，再保存返回首页；轨道距分隔线 12.58px，页面异常为 0。此为本机原生窗口检查，不宣称完整系统 DPI 覆盖。

- 实体 Android 原生房主 + Windows 打包原生客人 + 同一 PC 上两个生产 C# 网络服务客人，完成四个实际参与者的同图竞分。

- 本轮开始时设备只有 `com.orbbound.game.lantest`，正式包 `com.orbbound.game` 未安装。先保存验收应用的原始 8 项本地存储及应用目录备份；测试结束后恢复全部原始键值，逐字符串比对完全相同，保留该应用，未卸载或清空。
