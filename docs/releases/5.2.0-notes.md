# Orbbound 5.2.0（预发布测试版）

5.2.0 将联机改为每名选手独立随机棋盘与供球，并统一双端消除动效和联机基础界面。延续深海军蓝、低高光、哑光球面与原有六种图案；稳定正式版仍保留 4.3.0。

## 本次更新

- 联机“随机竞分”和“连锁对战”分别为每名选手生成初盘、后续波次及供球。相同难度保持相同球数和颜色配额，棋盘位置独立打乱；房主仍维护完整权威状态，重连不会重新抽取。
- 建盘、供球与来袭行使用分开的随机用途。单机、固定关卡及已有存档不采用新的联机生成规则。
- 直接消除与连带掉落共用命中起点、720ms 时长和渐隐曲线。球体保持原尺寸，散开和下落沿已确认 demo 的加速抛物线播放。
- 增加细粒与短尾。Windows 主棋盘最多 192 个、Android 最多 144 个，同时清除与连续发射共享当前棋盘预算；双端普通效果均保留粒子。
- 设置改为“减少消除效果”：关闭粒子、散落和旋转，保留 320ms 原位淡出。正常发射、装填、按钮和首页动效继续保留；系统减少动态偏好单独生效。
- 联机复用本平台其他模式的基础面板、HUD、下一球与操作样式。Windows 保留三栏；Android 保留竖屏普通/沉浸布局，对手信息以紧凑区域增加。暂停投票、恢复、认输及联机计时仍使用真实联机语义。
- 历史同图竞分记录保留旧规则名称，新局使用“随机竞分”。

## 安装与联机

Android 沿用正式包名与发行签名，可从 5.1.0 覆盖升级保留数据。Windows 完整解压后运行 `Orbbound/Orbbound.exe`，继续使用系统共享 WebView2 环境。

本版联机消息封装仍为 v3，规则指纹更新为 `7ca7ef0a`，内容指纹为 `f942c2f9`。**5.2.0 不能与 5.1.0 / 4.7.0 等旧规则版本联机**，请所有参与者更新到相同版本。

验收结果与实际覆盖范围见[验证记录](5.2.0-validation.md)，文件大小及 SHA-256 见[产物清单](5.2.0-artifacts.json)。

本轮 634 项共用自动测试、22 项 Android JVM 和 125 项 Windows 原生检查通过。Windows 完成真实鼠标通关与失败流程；Android 完整/减少效果均保留实际录屏。实际双设备完成四人竞分（另含两名同机 C# 客人）及纯双设备对战自然结算；正式 Android 覆盖升级后 5 项存档、历史和设置值与升级前完全一致。UI 样例已确认。
