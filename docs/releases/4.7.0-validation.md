# 4.7.0 验证记录

验证日期：2026-10-19。基线：4.6.0 / `21fe392`。以 prerelease 测试版交付，4.3.0 稳定正式版保留。

## 自动测试、构建与资源

- 全量 Vitest：52 个文件、574 项测试通过，失败/跳过均为0；TypeScript 检查通过。
- 新增及扩展回归覆盖主页落点双球相切、路线/位移同源、下一球实际装填阶段、终局首次记录幂等、存储失败保留恢复副本、跨启动拒绝回放已结束存档、弹窗来源与迟到事件隔离、导入失败后确认页仍可关闭，以及联机信息分组。
- Windows 打包流程共125项原生检查通过：15 shell、12 bridge、98真实TCP/UDP。
- Android 使用JDK21强制 `:app:testDebugUnitTest --rerun-tasks`，63个Gradle任务实际执行；4套共22项JVM测试通过，失败/错误/跳过均为0。箭头后续修复只改CSS，沿用本轮原生代码测试结果。
- 最终Windows版本4.7.0.0，保持既有未签名发行方式；APK实际版本4.7.0 / 40700，v2/v3签名通过，发行证书与4.6.0相同。
- 双端包内各5项网页构建资源逐文件SHA-256一致；另核对Windows包14个文件和APK public目录7个文件，无差异。最终[产物清单](4.7.0-artifacts.json)对应用户反馈箭头重叠修复后的重新构建，不使用首轮候选包哈希。

## 浏览器界面

- Windows模式预览中实际完成无尽主动结算，分别使用结果顶部关闭、Esc、底部首页和遮罩点击，均回主页、隐藏终局棋盘与弹窗。首次练习关闭回模式配置，跳过练习后正常开局。
- 关卡详情关闭回选关；限时配置选择困难/10分钟，打开排行、再进入规则说明，Esc回原榜，关闭记录回配置后仍保留困难/10分钟；设置详情Esc回分类，再完成回来源。
- 结果标题居中误差小于0.001 CSS px。用户指出的重开文字与箭头重叠已改成对称三列；320×568、393×851、1280×720实际DOM边界测量均无文字/箭头相交，按钮在视口内。
- 四个浏览器模拟会话完成四人对战准备、开局、自然到时结算及再来一局。393×851、320×568、360×640、568×320、851×393均量测到预期实际布局视口，7个主要操作/对手按钮均在视口内且中心命中，时间标签单行。短横屏长昵称投票的同意/拒绝按钮均可见且中心命中。
- 联机预览在393×851为40px，在320×568/360×640普通竖屏为30px，与单机共用同平台尺寸定义；小图绘制预算和主图展示状态更新入口保留。
- Windows最终包原生启动成功，UI Automation读取到4.7.0主页及原有闯关/限时存档入口。原生截图工具仍返回 `FrameArrived timed out`，本轮不将浏览器画面计为Windows原生视觉/DPI验收。

浏览器结果是预览验证，不能替代安装版原生视觉/DPI或真实局域网设备验收。响应式尺寸检查采用指定标签页开发者设备度量；部分宿主截图会按原宿主画幅缩放，尺寸与命中结论取实际DOM测量，不以缩放后的PNG像素推断设备尺寸。

## 实体Android安装与页面

- Android16实体手机从4.6.0原签名覆盖至4.7.0候选，再覆盖箭头修复后的最终包，均成功，未卸载或清空数据；旧无尽0分存档入口仍在。
- 用新建限时测试局验证游戏菜单→设置→完成回原菜单，主动结算后顶部关闭及Android系统返回均回首页。测试未用已有无尽存档执行结算。
- 最终包再次创建限时测试局并主动结算，真机截图确认重开主按钮整行显示、文字居中、箭头独立；修复未只停留在浏览器预览。
- 最终包作为手机房主，与同一PC上3个生产C#网络服务客人完成四人同图竞分；实际地址复制、准备/开局、主图发射、观战及返回自己、暂停/全员恢复均通过，180000ms自然结束并自动显示结果页。对局结束前无驱动错误或异常断线。
- 真机“剩余时间”标签单行，延迟独立显示；联机与单机下一球的球体均为120设备像素（本机对应40 CSS px），对手卡片、时间及操作没有原版的窄列断字和空状态大卡片。
- 该四人验证为1台实体Android＋1台PC上3个headless生产服务客人，不是4台实体设备，也不代表Windows完整游戏UI联机验收。手机保持原有精细画质/沉浸操控等设置，未清理旧记录或无尽存档。
