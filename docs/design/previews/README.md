# ORBBOUND Windows 5.0.0 离线交互预览

[打开预览 HTML](ORBBOUND-Windows-5.0.0-preview.html)

将 HTML 文件下载到本地后，用现代桌面浏览器打开即可查看；单文件离线运行，不需安装依赖或启动服务器。GitHub 不会在线执行该 HTML。

首页演示持续自动循环。点击首页底部“局内动效”可观看局内连击、下压预警、通关和失败循环；“切换自由试玩”进入手动试玩，P 暂停、Esc 回首页。

这份预览用于评审视觉、动效和导航。棋盘与规则做了简化，排行榜使用示例数据，没有连接生产存档、正式关卡规则或局域网服务。循环胜败只存在于观察预览中。
