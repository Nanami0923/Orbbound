# ORBBOUND 5.2.0 方案演示

[完整修改方案](../../docs/design/5.2.0联机随机与消除动效修改方案.md) · [独立 HTML demo](Orbbound-5.2.0-motion-demo.html)

这是独立的视觉和随机策略样例，没有改动正式 5.1.0 程序、安装包、游戏存档或 GitHub 发布。

## 打开与操作

直接双击 `Orbbound-5.2.0-motion-demo.html` 即可离线打开，无需安装依赖。文件内嵌全部样式、脚本及原球面图案，没有外部资源请求。

- 宽屏默认双端并排，窄屏默认 Android 竖屏；可自行切换布局。
- 默认 1× 自动循环；支持暂停/继续、0.5×、拖动时间轴。
- 完整效果：两类球同时向外轻抛，沿抛物线加速散开和下落，720ms 等大淡出，Windows/Android 保留粒子。
- 减少效果：无粒子、散落或旋转，两类球保留 320ms 原位淡出，发射仍可见。
- 随机页展示四人的独立棋盘、八球序列和“新一局”；这是本地生成策略样例，不是真实联机对局。

## 源码与生成

```powershell
node prototypes/5.2.0/build-demo.mjs
node --test prototypes/5.2.0/motion-model.test.mjs
```

`motion-model.mjs` 定义时间线、加速度、粒子及独立随机模型；`app.js` 渲染 Canvas 和交互；`shell.html` / `style.css` 提供双端预览布局。生成器从项目现有素材读取六种图案和配色，打包为单个 HTML。

## 验证范围

纯模型测试覆盖两类球逐时刻 pose 一致、scale 恒为 1、基础淡出、加速散开、先轻抛再下落及空间抛物线校验、粒子预算与逐球分配、独立随机复现及固定种子向量。

浏览器验证使用 Microsoft Edge：完整/减少效果、平台切换、暂停、慢放、时间轴、四人随机及新一局、1440×1000 / 393×851 / 320×568 布局、HTTP 及 file:// 打开、无存档访问和外部请求。原始报告和截图保存在本机 `.build/qa-5.2.0/demo-qa/`。

抛物线版本已通过 7 项纯模型测试与 49 项浏览器检查；位置采样符合指定的二次曲线，目视检查确认先轻抛、再下落。当前应用内演示页已刷新并保持循环播放。

这些验证仅针对本 demo，不等同正式 5.2.0 的真实物理、联网、安装、性能或设备验收。
